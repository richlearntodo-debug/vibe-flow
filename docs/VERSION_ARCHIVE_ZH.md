## V1.4 与 V1.5 的关系

V1.4 和 V1.5 属于同一轮快捷键体验升级。V1.4 先完成手动 Profile、应用发现、Browser Back 和执行回执，但没有形成完整可发布体验；V1.5 在同一基础上补齐实体键盘快捷键录制、Smart Profiles、配置校验和用户教程，因此 V1.5 是推荐结果，V1.4 只做可追溯归档。

[查看两版合并更新说明](RELEASE_NOTES_ZH.md) · [查看 V1.5 图文教程](V1_5_USER_GUIDE_ZH.md)

## 下载说明

- `VibeFlow-Setup.exe`：推荐，支持开始菜单、覆盖升级和标准卸载。
- `Vibe-Flow-Windows-x64.zip`：免安装版，必须完整解压后运行 `VibeFlow.exe`。
- `SHA256SUMS.txt`：用于核对安装包和 ZIP 是否完整。
- `Source code (zip/tar.gz)`：源码快照，普通用户不要下载。

覆盖升级前建议从系统托盘退出旧版本。排查问题时只保留一个版本运行，避免多个进程同时占用蓝牙麦克风。
