# 言灵 Vibe Flow Remote 2.0.0 候选版更新说明

Release status: candidate。尚未发布为正式稳定版，仍需完成真机和安装生命周期门禁。

## 2026-09-09 增量：录音键 F5 隔离与输入落点实测结论

- **RC003 录音键不再刷新浏览器/页面**：无签名过滤器时改用“RC003 在线范围”的钩子隔离（实测本机钩子先于 Raw Input、钩子抑制会取消对应 Raw Input，用户态无法逐事件判源）。录音键的按下/松开仍由语音状态机精确处理；遥控器不在线时普通键盘 F5 直通。真机验证：浏览器前台按录音键不再刷新。
- **输入落点结论（真机对照）**：路径 A（手动聚焦输入框）与路径 B（语音页选择常用应用并学习输入框）在 ChatGPT 桌面端均已真机走通——按住说话→松开→文字自动进入输入框，松开不发送，按确认键只发送一次。使用的链路为 **Windows 语音输入**（Win+H）。
- **微信输入法限制（第三方，已对照实测）**：微信输入法语音在本机把识别文字放进剪贴板（ChatGPT 与记事本均实测；不经过 Vibe Flow 单独使用时同样如此）。按用户“只用微信输入法”的要求，本增量加入**受控粘贴投递**：微信输入法链路的每次确认会话结束后，仅当目标输入框刚被验证为“可写编辑框且持有键盘焦点”时，自动执行一次 Ctrl+V 把输入法自己的剪贴板文字粘贴进输入框；不读取/保存/上传文字，不自动回车、不自动发送，焦点未验证或用户已切走时跳过并提示手动粘贴。默认语音工具保持微信输入法；Windows 语音输入（可直写）仍可在语音页切换。
- **开机键（电源）实测**：按键可上报（vk 0xFF/scan 0x5E），但会同时打开遥控器麦克风流并与语音键重连变体相同，无法安全映射动作；不修改 Windows 系统电源键行为。快捷键矩阵（方向/功能/Home/TV/确认）真机回归通过。
- 键盘桥接在 RC003 设备变更（蓝牙重连/移除）时统一释放进行中的注入按键，避免修饰键滞留；录音键防卡死看门狗与重复边沿去重日志收敛。

## 当前产品范围

V2.0 候选版现在聚焦一条可理解、可回退的语音输入路径：

- “首页”只展示设备、语音和当前问题，并提供下一步入口；
- “快捷键”保留 V1.5 的 Profiles、实体键映射、组合键录制和 Bridge ACK 状态；
- “语音”展示冻结录音链路、语音工具和工作流状态；
- “自检”展示真实证据、影响、错误码和修复入口；
- “设置”管理外观、后台行为、隐私与诊断。

便签本、Notes Deck、便签 AI 整理及其入口不属于当前产品范围。历史源码、旧数据和归档文档不会被删除，但生产 Host 不提供这些页面，也不会读取或迁移普通转写文字。

## 稳定性与兼容

- 升级不覆盖 V1.5 语音工具、映射、Profiles、Smart Profile 状态、主题和后台设置；
- Smart Focus 工作流必须由用户学习并立即测试后才能保存为默认目标；未验证时不会发送按键或粘贴；
- 所有异步操作使用 idle/checking/running/success/warning/error/canceled 状态，不把动作派发写成外部完成；
- 关闭新增入口后，原有 V1.5 快捷键和语音行为保持不变。

## 冻结不变

Capture 继续为 `1.2.1.0`，录音内核 `v1.0.3`，按住开始、松开结束，设备控制约 60 秒边界，`gain=1.0`、`speech`、`drainMs=180`。没有 MIC_EXTEND、自动续接、转写读取、剪贴板文字回填或自动 Enter。

## 验证状态

构建、自测、工作流专项、配置迁移、候选包哈希和 UI 资源测试已有自动证据。RC003 完整矩阵、第三方语音工具、ChatGPT 输入框实际落点、Windows 10/11、完整 DPI、VB-CABLE 重启恢复和安装生命周期仍标为未验证。
