# Vibe Flow V2.0 候选版兼容性矩阵

> 更新时间：2026-09-05。V1.5 的历史实测不能自动升级为 V2 最终二进制证据；这里明确区分稳定基线、设计支持和候选待复验。

## 推荐组合

| 项目 | 已验证基线 | 状态 | 说明 |
| --- | --- | --- | --- |
| 遥控器 | 小米蓝牙语音遥控器 RC003 / MI RC | V1.5 已验证；V2 候选待复验 | 较早录音有单 generation 真实证据；最终 Host/Bridge 的逐键与 100 次循环未完成 |
| 系统 | Windows 10 / 11 x64 | 设计支持，候选未验证 | 需要干净系统安装、升级、休眠恢复和 DPI 矩阵 |
| 音频桥 | VB-Audio VB-CABLE | 已验证 | `CABLE Input` 为播放端，语音工具读取 `CABLE Output` |
| 微信输入法 | `Ctrl + Win`、切换触发、80 ms | 已验证稳定档案 | 用户必须确保微信输入法与言灵快捷键一致 |
| Typeless | 自定义工具快捷键 | 已完成实际转译验证 | 具体快捷键以用户安装版本为准 |
| 豆包输入法 | — | **V2.0 起不提供** | 实测其安全过滤会忽略全部模拟输入、语音面板只采自选麦克风且无可用的自动路径；不再作为可选语音工具，历史取证见 `docs/V2_0_TECH_MOAT_RESEARCH_ZH.md` |
| Windows 语音输入 | `Win + H` 或用户配置 | 设计支持 | 依赖 Windows 语言包、在线语音服务与当前区域设置 |

## Windows 与蓝牙

| 组合 | 状态 | 发布结论 |
| --- | --- | --- |
| Windows 11 x64 + RC003 | V1.5 有开发机证据；V2 候选待复验 | 不能把旧二进制证据写成 V2 通过 |
| Windows 10 x64 + RC003 | 应用与构建目标支持 | 需要更多社区真机样本，不能宣称所有版本均已验证 |
| 内置蓝牙 / USB 蓝牙适配器 | 取决于 Windows 是否暴露 RC003 ATVV 服务 | 先运行应用内“自检”；请反馈芯片、驱动版本和检测结果 |
| Windows on ARM | 未验证 | 当前安装包为 x64，不列为支持平台 |
| macOS / Linux | 不支持 | 当前版本依赖 Windows Raw Input、Win32 和音频设备模型 |

## 实体按键能力

| 按键 | V2 候选状态 | 备注 |
| --- | --- | --- |
| 录音 | 冻结实现；最终候选待复验 | 按住说话、松开结束；冻结 Capture 内核；单段约 60 秒 |
| 上 / 下 / 左 / 右 | 待复验 | 原生方向或一个已验证动作 |
| 中间确认 | 待复验 | 默认 Enter，可配置 |
| Home | 待复验 | 短按与长按可分别配置 |
| TV | 待复验 | 默认持久任务视图，可配置单击动作 |
| 功能键 | 待复验 | 默认短按复制、长按粘贴，可配置 |
| 开机 / 返回 / 独立音量 | 不支持 | 当前 RC003 与 Windows 组合没有稳定事件，不提供虚假映射 |

## 提交新的兼容结果

请使用“问题反馈”或“功能建议”Issue Form，并附上：

1. Vibe Flow 版本、Windows 版本号与系统架构；
2. 遥控器型号/固件标识和蓝牙适配器型号；
3. 语音工具与触发快捷键；
4. 应用内自检的脱敏摘要；
5. 复现步骤和成功/失败次数。

不要提交录音、转译文字、蓝牙地址、完整 HID 路径或包含隐私的日志。
