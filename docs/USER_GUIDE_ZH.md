# 言灵 Vibe Flow 使用教程

这份教程面向第一次使用 RC003 蓝牙语音遥控器的 Windows 用户。正常情况下，完成一次设置后，以后只需要聚焦输入框并按住录音键。

## 使用前准备

请先确认：

- Windows 10/11 电脑具有蓝牙功能。
- 遥控器型号为 RC003 / MI RC，带麦克风录音键。
- 微信输入法已经安装，并且按下 `Ctrl + Win` 可以启动语音输入。
- 已从 [VB-Audio 官网](https://vb-audio.com/Cable/) 安装 VB-CABLE。

## 第一步：连接遥控器

1. 打开 Windows **设置 > 蓝牙和设备**。
2. 让遥控器进入配对模式。
3. 添加设备，选择 `MI RC` 或“小米蓝牙语音遥控器”。
4. 等待 Windows 显示“已连接”或“已配对”。

如果遥控器以前连接过电视或其他电脑，先断开旧设备，再重新配对。

## 第二步：安装音频通道

言灵需要 VB-CABLE 把遥控器音频交给微信输入法。

1. 从 [VB-Audio Cable](https://vb-audio.com/Cable/) 下载并安装 VB-CABLE。
2. 安装完成后按安装程序提示重启 Windows。
3. 在 Windows 声音设置中确认可以看到 `CABLE Input` 和 `CABLE Output`。

音频方向：

```text
言灵播放到 CABLE Input -> 微信输入法从 CABLE Output 收音
```

## 第三步：首次启动言灵

1. 从 [GitHub Releases](https://github.com/richlearntodo-debug/vibe-flow/releases/latest) 下载 `Vibe-Flow-Windows-x64.zip`。
2. 解压到一个固定目录，不要直接在压缩包里运行。
3. 双击 `VibeFlow.exe`。
4. 按首次设置页依次检查蓝牙、VB-CABLE 和微信输入法麦克风。
5. 建议保留“开机后自动启动言灵”，以后无需手动连接。

![首次设置页面](images/00-first-run.png)

在微信输入法中选择麦克风时，请选择 **CABLE Output**。勾选完成确认后，点击“完成并开始使用”。

## 第四步：验证语音输入

1. 打开记事本、浏览器输入框、VS Code、Cursor 或 Codex。
2. 用鼠标点进输入框，确保光标正在闪烁。
3. 按住遥控器录音键，靠近遥控器说一句完整的话。
4. 说完后松开录音键，等待微信输入法回填文字。

首页显示“已准备好”，底部四项状态正常时即可使用。

![言灵总览页面](images/01-overview.png)

## 语音听写页面

“语音听写”页用于确认通道是否就绪，并查看上一段语音的时长与电平。

![语音听写页面](images/02-dictation.png)

- **测试微信语音**：验证电脑上的 `Ctrl + Win` 是否能调起微信输入法。
- **检查麦克风设置**：打开 Windows 声音设置。
- **麦克风音量**：默认建议 `1.0x`。只有声音确实偏小时再小幅提高，过高会导致失真。

## 按键快捷方式

言灵只展示已经通过 RC003 真机验证的单击和长按操作。

![按键快捷方式页面](images/03-shortcuts.png)

| 按键 | 默认行为 | 是否可配置 |
| --- | --- | --- |
| 录音键 | 按住听写 | 固定 |
| 确认键 | Enter | 可以 |
| Home | 显示桌面 | 可以 |
| TV | 打开任务切换器 | 可以 |
| 功能键 | 命令面板 | 可以 |
| 方向键 | 短按移动；长按上/下调音量 | 固定 |

修改后点击“立即应用”。TV 打开任务切换器后，使用左右键选择程序，再按确认键进入。

## 连接与诊断

遇到连接、按键或录音问题时，打开“连接与诊断”。

![连接与诊断页面](images/04-diagnostics.png)

建议按这个顺序排查：

1. 点击“检查连接”，确认遥控器为已连接。
2. 点击“全面检测”，检查蓝牙、ATVV 和 VB-CABLE。
3. 按一次录音键，再点击“刷新”，观察是否出现 `STREAM START`。
4. 仍有问题时点击“导出诊断”，提交 Issue 时附上导出的文本。

诊断前请自行检查并删除不希望公开的内容。不要上传录音、输入文字、蓝牙地址或其他个人信息。

## 偏好设置

![偏好设置页面](images/05-settings.png)

- **打开言灵后自动连接遥控器**：建议开启。
- **关闭主窗口后继续运行**：建议开启，言灵会留在系统托盘。
- **登录 Windows 后自动启动言灵**：按个人需要选择。

## 常见问题

### 按录音键没有任何反应

先在“语音听写”页点击“测试微信语音”。如果手动测试也不能启动微信输入法，请先在微信输入法中把语音快捷键设置为 `Ctrl + Win`。

如果手动测试正常、遥控器录音键无反应，打开“连接与诊断”并点击“全面检测”，然后重新连接蓝牙。

### 能启动语音输入，但识别内容缺失

确认微信输入法选择的是 `CABLE Output`，不要选择电脑内置麦克风。保持遥控器麦克风距嘴部约 10-30 厘米，先使用 `1.0x` 音量；只有电平长期偏低时再逐步提高。

### 按键突然全部失效

在系统托盘中退出言灵后重新打开。如果蓝牙状态不是已连接，请在 Windows 蓝牙设置中先断开再连接遥控器。

### 返回键或独立音量键不能使用

在已验证的 RC003 Windows 蓝牙链路中，这些物理键没有上报可用事件。言灵不会伪装支持它们。系统音量请使用长按方向上/下。

### 为什么没有组合键

RC003 不稳定地同时上报功能键和第二个按键，容易造成误触或漏触。当前版本只保留经过真机验证的单击、顺序选择和长按功能。

## 隐私与卸载

言灵在本机解码并转发音频，不提供云端转写，不读取微信输入法产生的文字，也不向微信或其他进程注入代码。

卸载前先在“偏好设置”关闭开机启动，再从系统托盘退出言灵，然后删除解压目录。VB-CABLE 可在 Windows“已安装的应用”中单独卸载。
