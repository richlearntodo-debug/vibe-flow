## 下载说明

- `VibeFlow-Setup.exe`：推荐，支持开始菜单、覆盖升级和标准卸载。
- `Vibe-Flow-Windows-x64.zip`：免安装版，必须完整解压后运行 `VibeFlow.exe`。
- `SHA256SUMS.txt`：用于核对安装包和 ZIP 是否完整。
- `Source code (zip/tar.gz)`：源码快照，普通用户不要下载。

覆盖升级前请先从系统托盘退出正在运行的旧版本。排查问题时只保留一个版本运行，避免多个进程同时占用蓝牙麦克风。
