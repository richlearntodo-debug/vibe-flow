# Vibe Flow V1.4 Preview 测试说明

> 状态：本地功能候选版。V1.3 本地稳定基线已单独冻结；本版本不提交、不打标签、不上传 GitHub，也不会覆盖已安装版本。

## 这次只解决什么

V1.4 增加可手动切换的快捷键 Profile、能够证明实体按键是否真正执行成功的回执，并修复本机应用目录与浏览器返回。它不修改语音链路，不增加长录音，不做前台应用自动识别。

### 快捷键 Profile

- `我的快捷键`：从 V1.3 升级时原样保存用户当前映射；
- `通用导航`：保留方向、确认、桌面、任务视图和复制/粘贴；
- `Vibe Coding`：提供撤销、重做、复制、粘贴和 Cursor 启动入口；
- `浏览器 AI`：提供翻页、返回和 ChatGPT 启动入口；
- `Terminal Agent`：提供终端和 Codex 启动入口。

“选择本机应用”现在统一显示正在运行和已安装两类结果。已安装目录合并 Windows AppsFolder、开始菜单、App Paths 和有效安装记录，并优先显示应用产品名与真实图标；“浏览其他 EXE”只作为找不到应用时的兜底。

浏览器 AI 的左键改用 Windows 专用 Browser Back 事件，不再在实体 Left 仍按下时注入 `Alt+Left`。Schema 30 中位于实体左键上的旧 `Alt+Left` 会自动迁移。

用户可以切换、新建、重命名、删除、导入和导出 Profile。Profile 只保存快捷键，不包含麦克风、VB-CABLE、输入法、增益或其他语音参数。导入文件必须通过格式、版本、动作和大小校验。

### 真实执行回执

首页的“最近一次快捷操作”显示：

- 实体按键与单击、短按或长按；
- 最终解析出的动作；
- 当前 Profile；
- 执行来源、时间和配置 revision；
- Bridge 返回的真实成功或失败结果。

页面按钮测试只能证明动作执行器可用；实体遥控器回执才证明完整的硬件路由已经走通。

## 升级安全规则

1. Schema 29/30 升级到 schema 31 时，现有映射进入“我的快捷键”，不会被模板覆盖；实体左键上的旧 `Alt+Left` 自动改为专用 Browser Back。
2. 切换 Profile 使用原子配置写入、Bridge 配置 revision 和加载确认。
3. Profile 导出不包含语音参数；完整配置导入仍强制保留稳定语音档案。
4. V1.4 候选包使用独立目录，不写入正式安装目录。
5. Power、返回和独立音量键仍不提供配置入口，因为当前 RC003/Windows 组合没有稳定事件。
6. 未安装签名过滤通道时使用 Raw Input 安全直通：动作可以执行，普通键盘不被抢占，但遥控器原始按键效果可能同时出现。

## 真机验收顺序

### A. 先复验语音基线

- [ ] 连续完成 100 次录音按下/松开；每次只产生一个会话；
- [ ] 按住至约 60 秒，期间持续有真实音频，松开后只结束一次；
- [ ] 微信输入法、Typeless 或当前已配置工具能把文字直接写入聚焦输入框；
- [ ] 没有第二个麦克风、剪贴板中转、重复触发或遗留热键；
- [ ] 蓝牙断开时会话自动结束，重连后无需重配。

任何一项失败，立即停止 V1.4 测试并继续使用冻结的 V1.3。

### B. Profile 与持久化

- [ ] 首次升级后“我的快捷键”与 V1.3 实际映射逐项一致；
- [ ] 四个官方 Profile 均可手动切换，页面卡片立即更新；
- [ ] 修改一个 Profile 后切换出去再切回来，修改仍保留；
- [ ] 重启应用和 Windows 后，活动 Profile 与每个 Profile 的映射均保留；
- [ ] 新建、重命名、删除、导出、导入各完成一次；
- [ ] 导入或切换前后，语音基线表中的值完全一致。

### C. 实体按键与回执

- [ ] 用实体 RC003 逐项按确认、Home、TV、功能键和四个方向键；
- [ ] 首页显示正确按键、触发方式、动作、Profile 和成功状态；
- [ ] 回执中的配置 revision 与 Bridge 当前加载 revision 一致；
- [ ] APP、HTTPS 网页、截图、系统动作和自定义快捷键各实测一次；
- [ ] “选择本机应用”同时显示正在运行与已安装应用，常用应用名称、Logo 和启动动作正确；
- [ ] 切换到“浏览器 AI”，实体左键可在浏览器返回上一页且不会额外移动输入光标；
- [ ] 失败动作显示失败，不把“请求已排队”误报成成功；
- [ ] 页面“测试”与实体按键的最终行为一致。

### D. 稳定性与兼容性

- [ ] 普通键盘冲突回归：F5、Home、方向、Enter、Apps 和反引号保持原行为；
- [ ] RC003 休眠/唤醒、蓝牙断开/重连、电脑睡眠/恢复后自动可用；
- [ ] 进程保持单实例，Host、Capture、Bridge 不重复；
- [ ] 浅色、夜间模式无重叠或截断；
- [ ] Windows 100%、125%、150% 缩放均检查首页、快捷键、语音、自检和设置页；
- [ ] 日志轮转生效，不保存录音或转译文字。
