# 言灵 · Vibe Flow Remote v1.3.0 更新说明

**定位：可靠快捷键与新手体验升级 · 录音核心保持 v1.2.1 稳定基线**

## 核心更新

### 快捷键真实可用

- 非录音动作只由带设备身份的 RC003 Raw Input 或专属过滤通道执行；低层 Hook 不再抢占普通键盘同名按键。
- 真机日志已定位并移除旧 Hook/Raw 配对循环；自检现在分别显示设备事件和真实动作事件，页面测试不再被当作实体链路证明。
- 四方向、确认、TV 支持单击动作；Home 和功能键支持短按、长按。
- 支持 APP、HTTPS 网页、编辑、系统、媒体、区域截图和自定义快捷键。
- “立即测试”必须等待桥接真实成功、失败或超时结果。
- 开机、返回和独立音量键没有稳定 Windows 事件，继续隐藏。

### 本机 APP 启动修复

APP 动作现在依次尝试：

1. 聚焦匹配的运行窗口；
2. 启动当前有效 EXE；
3. 使用 Windows 开始菜单 AppID。

选择器显示应用图标、名称、路径或来源，并支持搜索运行中/已安装应用。配置保存后由 bridge revision ACK 确认生效。

已运行 APP 只有在 Windows 确认目标窗口成为前台后才报告成功。旧候选版绑定到开机键的 APP/网页动作会迁移到空闲的 Home 长按，开机键本身不再生成运行时映射。

如果已运行窗口无法切到前台，动作会直接报告失败，不再继续启动第二个 APP 实例。候选包中的冻结 Capture 也固定使用 Host 所需的 `VibeMicAtvvCapture.exe` 文件名，确保全新解压即可启动语音链路。

### 五项首次设置

原 11 个技术步骤合并为设备与用法、遥控器、音频通道、真实听写、开机即用五项任务。进度自动保存，VB-CABLE 安装重启后可继续。

### 配置与诊断

- 新增通用导航、Vibe Coding、媒体控制三套简单方案。
- 新增配置备份、导入和恢复上次。
- 旧配置自动迁移，导入时强制保留稳定语音档案。
- 诊断导出隐藏用户目录、电脑名、设备路径、地址、URL 和应用目标。
- 按键健康信息新增路由来源、隔离级别、RC003 边沿、动作边沿、最近动作和过滤器状态。

### UI

- 默认浅色，支持夜间和跟随 Windows。
- 启用 Per-Monitor V2 DPI awareness，并在高缩放下将窗口限制在当前工作区。
- 快捷键页使用实体遥控器布局、实时高亮、动作卡和独立测试。
- 五个主页面和五项向导均已生成真实浅色截图；核心页面已复查深色模式。

## 冻结录音基线

| 项目 | 值 |
| --- | --- |
| Capture 文件 | v1.2.1 固定二进制 |
| 录音内核 | `v1.0.3` |
| 状态机 | `v11` |
| 交互 | 按住说话，松开结束 |
| 单段边界 | 约 `60 秒` |
| 增益 / 处理 / 排空 | `1.0` / `speech` / `180 ms` |
| 端点 | `CABLE Input` -> `CABLE Output` |
| 微信输入法 | `Ctrl + Win` / toggle / `80 ms` |

没有加入长录音、自动续接、云端转写、剪贴板回填、宏、双击或自动 Profile。

## 发布状态

旧候选版真机日志已证明：Hook 先拦截会使该 Windows 蓝牙栈不再投递对应 Raw Input，导致页面动作测试通过、实体遥控器却不执行。当前候选已改为 Raw Input 独立执行、Hook 非录音键直通，并完成编译和三组件自测。无副作用精确拦截仍需要 Microsoft 签名的 RC003 专属过滤驱动；驱动缺失不会再被误报为动作链路故障，但 UI 会显示“安全直通”及其边界。RC003 100 次按下/松开、公开按键逐项实测、普通键盘回归、重连、睡眠唤醒、Windows 重启、覆盖升级和 125%/150%/200% DPI 矩阵完成前，v1.3 仍是 hardware candidate，不替代 v1.2.1。当前安装包未配置 Authenticode 签名。
