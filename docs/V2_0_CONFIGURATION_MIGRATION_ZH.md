# V2.0 配置迁移说明

> **范围提示（2026-09-08 起）：** 本文件描述当前 Host 的配置迁移。便签本、Notes Deck 及其 AI 配置不属于当前 schema；历史未知字段会保留但不会执行。

## 保留的 V1.5 设置

升级不会重置语音工具、语音快捷键、触发方式、稳定语音参数、实体键映射、Profiles、Smart Profile 开关/锁定/回退、主题、开机启动和托盘设置。主配置 schema 继续为 `32`，Bridge schema 继续为 `7`。

主配置按原子写入流程保存：先写临时文件，再替换主文件并维护 `.bak`。顶层未知字段会保留；Profile 按 `id` 合并未知字段，Custom Button 按 `slot` 合并；`mappings` 使用用户当前完整集合，已删除映射不会从 sidecar 复活。

## V2 独立数据

| 文件 | schema | 内容 |
| --- | --- | --- |
| `focus-targets.json` | `1` | Smart Focus 描述符和验证状态，不含控件文字 |
| `project-spaces.json` | `1` | 项目现场数据；保留用于 Capture & Ask 目标解析，不再提供用户编辑入口 |
| `quick-entries.json` | `1` | 历史 APP 入口数据；仅作数据保留在磁盘，不参与当前 UI |

文件位于当前用户的 Vibe Flow `UserData` 目录，使用原子保存、备份、损坏恢复和幂等迁移。未知字段可以保留，但不会作为命令执行。未来 schema 高于当前程序支持范围时，程序只读保护并停止启动运行服务，避免旧版本覆盖新数据。

## 升级行为

- 升级用户不会自动创建新按键绑定或目标。
- Smart Profiles 保持原值；不会自动开启。
- Context Deck 不常驻；HUD 可关闭。
- 配置保存不等于运行时生效。涉及按键的保存必须等待匹配进程和 revision 的 Bridge ACK。
- 安装器按中央主配置、中央备份、旧安装主配置、旧安装备份顺序恢复；解析由 Host 的真实 JSON 解析器完成。
