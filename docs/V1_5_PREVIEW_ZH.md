# Vibe Flow V1.5 发布验收记录

> 状态：V1.5.0 正式发布所使用的候选验收说明。V1.4 已作为不完整预览归档；V1.5 通过发布确认后成为推荐正式版。

## 本次目标

V1.5 只增加两项高价值能力：**直接录制键盘快捷键**和**Smart Profiles（按前台应用自动切换快捷键方案）**。录音内核、蓝牙音频路径、输入法唤起参数和已经验证的实体按键行为全部冻结。

设计参考了 `remote-mic-app` 的快捷键捕获思路，以及 Stream Deck Smart Profiles 的“应用决定当前配置”原则。首版没有加入宏、多步骤动作、条件执行或插件市场，避免把未经真机验证的复杂状态带进稳定链路。

## 亮点一：直接录制键盘快捷键

配置任一可用遥控器按键时，点击 **录制键盘快捷键**，再在真实键盘上按下目标组合即可。

1. 不需要输入 `control`、`shift` 或快捷键名称；
2. 完整按住组合键，全部松开后完成记录；
3. 录制期间按键被临时拦截，不会误触发系统或前台应用；
4. 支持左右 Ctrl、Shift、Alt、Win，`F1` 至 `F24`、方向键、常用系统键和 OEM 符号键；
5. 支持 `Ctrl + Win` 这类只有修饰键的组合；
6. 最多五个键且只能有一个主键，拒绝半截组合、未知键和 `Ctrl + Alt + Delete`；
7. 保存后必须收到 Bridge 配置 revision 确认，失败会明确提示，不会假报“已生效”。

录制器只保存最终组合，不保存键盘输入历史，也不会记录输入内容。

## 亮点二：Smart Profiles

Smart Profiles 默认关闭，原有手动 Profile 行为保持不变。开启后：

- 为每个 Profile 勾选本机应用；同一进程只能绑定到一个 Profile；
- 前台应用稳定切换后，Bridge 自动启用对应快捷动作；
- 没有匹配应用时使用用户指定的回退 Profile；
- 点击 **锁定当前** 可固定屏幕上真实生效的 Profile，再次点击恢复自动切换；
- 首页显示当前生效 Profile，自动切换后提供轻量提示；
- 自检健康信息记录生效 Profile、匹配状态和进程名，不记录窗口标题或用户文本。

内置建议绑定：

| Profile | 建议进程 |
| --- | --- |
| Vibe Coding | Cursor、VS Code、Windsurf、Codex |
| 浏览器 AI | Chrome、Edge、Firefox、Brave |
| Terminal Agent | Windows Terminal、PowerShell、cmd、WezTerm |

自动检测每 `250 ms` 读取一次前台进程，并使用 `350 ms` 防抖，避免 Alt+Tab 经过中间窗口时频繁闪切。Vibe Flow 自身窗口不会抢走当前工作 Profile。切换只替换已经校验的快捷动作表，不重启 Host、Bridge 或 Capture，也不修改任何语音参数。

## 配置步骤

### 录制自定义快捷键

1. 打开 **快捷键**，选择一个可配置的实体按键；
2. 点击 **录制键盘快捷键**；
3. 在键盘上按住完整组合，例如 `Ctrl + Shift + P`；
4. 全部松开，确认界面显示的组合；
5. 点击 **使用此快捷键**；
6. 看到“已保存并生效”后，先用页面测试，再用实体遥控器验证。

### 开启 Smart Profiles

1. 在 **快捷键** 页开启 **智能切换**；
2. 选择一个 Profile，点击 **绑定应用**；
3. 搜索并勾选需要使用此方案的应用，保存；
4. 为其他 Profile 重复配置；
5. 通过 **设为回退** 指定无匹配应用时的行为；
6. 切换到 Cursor、浏览器和终端，确认首页生效 Profile 与实体按键结果一致；
7. 临时不希望自动切换时点击 **锁定当前**。

## 真机验收清单

### A. 稳定语音回归

- [ ] 连续完成 100 次录音按下/松开，每次只创建和结束一个会话；
- [ ] 按住至约 60 秒，真实音频持续存在，结束后文字直接进入聚焦输入框；
- [ ] 没有双麦克风、剪贴板中转、重复输入法热键或语音参数变化；
- [ ] 蓝牙断开、遥控器休眠和 Windows 睡眠恢复后无需重新配置。

任何一项失败，都应停止升级并导出诊断；修复并重新通过该项后再继续。

### B. 快捷键录制

- [ ] 分别录制并测试 `Ctrl+Shift+P`、`Ctrl+Win`、`Alt+F4`、`Win+Shift+S`；
- [ ] 测试左右修饰键、一个 OEM 符号键和一个单独修饰键；
- [ ] 录制期间组合键不会在其他应用中执行；
- [ ] 两个主键、未知键和保留组合不能保存；
- [ ] 保存、切换 Profile、重启应用和重启 Windows 后映射均保持一致；
- [ ] 页面测试结果与 RC003 实体按键的执行回执一致。

### C. Smart Profiles

- [ ] 默认关闭时与 V1.4 手动 Profile 行为完全一致；
- [ ] Cursor、浏览器和终端各绑定一个 Profile，前台切换后动作表正确变化；
- [ ] Vibe Flow 窗口、未绑定应用和快速 Alt+Tab 不产生错误闪切；
- [ ] 回退、锁定当前、解除锁定三种状态均与界面文字一致；
- [ ] 一个应用重新绑定到另一 Profile 后，旧绑定自动移除；
- [ ] 删除、导入或损坏配置恢复后，活动与回退 Profile 始终有效；
- [ ] 自动切换前后录音进程 PID、Capture 哈希和稳定语音参数不变。

### D. UI 与兼容性

- [ ] 浅色、深色和跟随 Windows 模式下无重叠、截断或低对比文本；
- [ ] Windows 100%、125%、150% 缩放检查首页、快捷键页和两个配置弹窗；
- [ ] 普通键盘 F5、Home、方向、Enter、Apps 和反引号保持原行为；
- [ ] RC003 休眠/重连后快捷键录制结果和 Smart Profile 绑定不丢失；
- [ ] 日志不保存录音、听写文字、窗口标题或完整用户路径。

## 自动验证与发布门禁

候选包生成前必须通过：

- Host 与 Bridge 编译；
- `VibeMic.exe --self-test`；
- `VoxDeckInputBridge.exe --self-test`；
- `npm test`；
- 冻结 Capture 源文件与二进制 SHA-256；
- 300 次页面切换资源测试；
- 浅色和深色 UI 截图检查。

自动测试通过不等于硬件验收通过。本记录与用户的真机确认共同构成 V1.5 发布依据；后续修改语音链路时必须重新执行完整 RC003 回归。
