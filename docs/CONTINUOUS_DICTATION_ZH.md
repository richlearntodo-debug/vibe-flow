# 按住说话与 60 秒边界

适用于言灵 · Vibe Flow Remote `v1.2.1`。

## 当前交互

1. 聚焦一个可编辑文本框。
2. 按下录音键，RC003 自然 ATVV 流启动语音工具和音频传输。
3. 持续按住并说话。
4. 松开后，RC003 自然结束当前音频流和工具会话。
5. 等待文字进入原文本框，再按确认键发送。

当前稳定模式单段最长约 `60 秒`。这是 RC003 在 Windows 上报告按键释放或结束 ATVV 流的物理边界，不是应用内倒计时。到达边界后应用会结束当前会话，用户可重新按住开始下一段。

## 为什么不再自动续接

旧方案尝试在遥控器物理流结束后主动重开音频，并保持同一个工具会话。真机结果显示，这会混淆“固件提前结束”和“用户真实松手”，造成：

- 松开后工具才被唤起；
- 旧会话未完全结束，新会话又开始；
- 必须再次点击才能结束；
- 第二个麦克风面板出现；
- 文字落入工具自己的剪贴板兜底。

v1.2.1 直接恢复 `v1.0.3` 捕获内核：遥控器自然音频流负责开始和结束，捕获组件不包含长录音续接状态机，也不发送 `MIC_EXTEND` 心跳。

## 防重复规则

- 输入桥接会去重重复 DOWN/UP。
- 捕获组件同一时刻只接受一个活动流代际。
- 重复开始和过期结束事件不能改变当前代际。
- 不主动重开 RC003 物理流，不创建续接会话。
- 蓝牙断开或应用退出会释放旧路由和旧会话。

## 文本输入规则

言灵不读取转译文字，也不通过剪贴板或 `Ctrl + V` 补写。录音开始前必须让目标文本框真正获得键盘焦点；仅把鼠标停在输入框上不等于聚焦。所选语音工具会把结果写入当时的系统焦点，因此焦点错误时应结束本次录音、重新单击目标输入框后再试。

## 验收

- 连续 100 次实体按住/松开。
- 10 秒、30 秒和约 60 秒三档录音。
- 每次只有一个麦克风会话和一个结束提示音。
- 松开后不再出现延迟启动。
- 聚焦输入框后由语音工具直接写入文字，全程不经过剪贴板。
- 达到约 60 秒边界后可正常开始下一段。
