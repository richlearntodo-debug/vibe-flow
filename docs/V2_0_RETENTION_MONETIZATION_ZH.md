## 0. 结论速览

1. **留存的第一杀手不是功能不够，而是「没在第一次会话里成功过」。** 行业基准：60–70% 的新用户从未达到激活里程碑，激活率中位数仅约 30%（Userpilot 547 家 / Lenny Rachitsky 500+ 产品，转引自 [Insight Lab](https://dev.to/insightlab/the-7-day-onboarding-window-why-most-saas-companies-lose-60-of-new-users-in-week-one-2mdd)）。本产品「连接不稳定 + 配置成本高」正是典型的**首次成功失败**。
2. **激活事件必须定义为一个可观测的物理动作**：【推断】「用户在向导内按住遥控器说话 → 文字出现在测试输入框 → 松手成功」。
3. **物理遥控器是本产品唯一无法被输入法厂商复制的留存资产**，天然绑定「手不离键、眼不离屏、可以不在桌前」三类场景（§3）。
4. **免驱动模式应是「体验模式 + 驱动失败兜底」，不应做成默认**：它消掉最大摩擦，代价是音质下降与房间声音被采集（§6）。
5. **商业化必须绕开转写能力与数据**：可持续付费点只有 **硬件套装 + 部署服务 + 企业批量/签名构建/更新通道**；硬件套装毛利约 40–55%，但需月销约 250–300 套才摊得动固定投入（§8，含假设）。

## 1. 留存与激活规律（有来源的事实）

**结论：激活＝用户第一次真实感受到核心价值的行为事件；延迟一天，留存掉一档。对本产品，激活必须发生在安装后的首次会话内。**

- 激活率中位数约 **30%**；60–70% 新用户从未激活（[Insight Lab 汇总 Userpilot 2024 报告与 Lenny Rachitsky 调研](https://dev.to/insightlab/the-7-day-onboarding-window-why-most-saas-companies-lose-60-of-new-users-in-week-one-2mdd)）。
- **首次会话决定一切**：未在头 3 天产生参与的用户流失概率约 90%；7 天内激活的队列第 12 个月留存高 **1.5–2.3 倍**（同上，引 Amplitude / Mixpanel 队列分析）。
- **首次成功时间的量化影响**：14 天内达到首次价值的客户留存 **82%**，30 天以上仅 **42%**；中位产品交付首次价值需 **22 分钟**，最优 **<5 分钟**；**每延迟 10 分钟转化率约损失 8%**；TTV 降低 20–50% 通常带来 30 天激活率提升 **10–30%**（同上，引 OpenView）。
- **激活要按「行为预测留存」定义，不要按「完成清单」**：Slack＝团队发出 2000 条消息（命中者长期留存 93%），Dropbox＝一台设备同步一个文件（同上）。
- **清单越长完成率越低**：4 项清单完成率是 8 项的 **4 倍**（同上，引 Appcues）。【推断】本产品向导对外应呈现 **4 项主检查**。
- **渐进披露**：第一周只展示核心工作流，第 2–4 周再按行为触发中级功能（同上）。
- 反面案例：开源桌面工具复盘显示「文档滞后于功能 + Windows 测试长期落后」会让新用户因**搞不定安装**直接流失（[Tabularis 复盘](https://tabularis.dev/blog/from-zero-to-1000-github-stars)）。本产品只有 Windows，没有「Mac 先跑通」的缓冲。

## 2. 漏斗拆解：下载 → 首次成功 → 日常习惯 → 长期留存 → 主动推荐

**结论：每环只给一个可量化目标 + 2–4 个具体交互，不用功能清单填漏斗。**

### 2.1 首次成功（T0，目标：安装后 10 分钟内出现第一段文字）
1. **「验真机」做成向导第 1 步通过标准**：按下任意普通键 → 立即显示「已收到实体按键」（现有真机校验提前到配对后第一屏）。
2. **「说一句话」作为唯一激活事件**：向导内置测试输入框，成功即点亮整页进度并本地记录时间戳（构成 TTV 指标）。
3. **失败即给动作，不给错误码**：每项失败直接给 1 个可点击动作（重装驱动 / 选设备 / 换触发键）。
4. **任何一步都能「跳过并继续」**：未完成项变成首页常驻待办卡片，而不是阻塞向导。

### 2.2 日常习惯（T1–T30，目标：7 日内 ≥3 天使用、单次会话 ≥3 次语音）
1. **开机自启 + 托盘常驻 + 图标状态色**（灰=未连接 / 绿=就绪 / 黄=录音中），让「它在待命」可见。
2. **每次成功上屏给一次极轻反馈**（HUD 一闪 + 可选提示音），把「说→出字」变成可感知闭环。
3. **首周「今日一句话」卡片**：只显示「今天 N 次 / 累计 N 字」，不显示内容。
4. **连续使用天数（Streak）**：当天至少 1 次成功即打卡；断签给一张「补签」，不清零。

### 2.3 长期留存（T30+，目标：周活跃 ≥4 天、形成固定键位与 Profile）
1. **Smart Profiles 从「切按键表」升级为「切整套配置」**（按键表 + 触发方式 + HUD 位置 + 输入目标策略）。竞品侧「按应用自动切换」已是标配：Typeless 免费档即含 per-app tones（[Typeless 定价](https://www.typeless.com/pricing)），superwhisper 的 Modes 可按前台应用自动激活（[评测](https://spokenly.app/blog/superwhisper-review)）。
2. **Profile 导入导出（本地 JSON）**：把「VSCode 键位方案」「会议演示方案」做成可交换方案，社区产出 → 用户为方案留下来。
3. **配置体检（每月一次）**：检测默认录音设备被系统更新改掉、CABLE 采样率错配、目标应用升级导致输入框定位失效，主动提示。
4. **更新通道可见**：关于页给出更新日志摘要；开源项目复盘显示「持续发布 + 诚实写清改了什么」比单次爆款更能建立信任（[Tabularis 复盘](https://tabularis.dev/blog/from-zero-to-1000-github-stars)）。

### 2.4 主动推荐（T90+，目标：分享率与二次购买）
1. **本地生成的「语音报告」图片**（只含元数据：累计字数、节省时间、连续天数、Top 3 场景）。
2. **硬件套装推荐码**：推荐成功给双方**延长更新时间**，而不是解锁功能。
3. **贡献入口**：一键导出脱敏诊断包 + issue 模板，把用户变成贡献者。

## 3. 物理遥控器 + 免费引擎：独有的留存场景

**结论：遥控器的价值不是「麦克风」，而是「一个可以离开键盘的物理按键生命周期」。**

**【推断】形态独有的三个机制**：① **盲操** —— 实体按键有固定手感，「按住→说→松开→送字」不必看屏幕，App 类工具做不到；② **离键距离** —— 竞品把听写绑在键盘快捷键上（Fn/Ctrl 长按），本产品把它从键盘解耦，这是「沙发/演示/单车」场景的唯一解；③ **离机摆放** —— 遥控器常驻电脑旁但不在键盘边，反而降低启动成本。

- **每天必用的高频刚需（留存主力）**：**Vibe Coding / AI 代理口述**（手不离键、眼不离屏，口述 prompt 比打字快数倍）与 **长文档 / 邮件 / 日报口述**（需要 30–60 秒连续段落，手机与鼠标都做不到「按住说完」）。
- **每周数次的场景（放大与传播）**：**会议 / 演示 / 直播远程输入**（人在讲台或镜头前，电脑不在手边，可在 10 米内输入搜索、备注、聊天；企业/教育可放大）；**沙发 / 客厅 / 投影**（电脑接电视，键盘不在手边，易沉淀）；**多任务并行**（一边听会一边口述到另一窗口，键盘切换会打断）。
- **情感黏性最强的一类**：**动感单车 / 站立办公 / 无障碍**（RSI、帕金森等无法久坐键盘前的人群），使用频率高、口碑扩散快，且是最有说服力的对外故事。

**竞争提示（有来源的事实）**：同形态竞品已存在 —— 开源项目 **SayAll / 无线麦**（`HD838A/remote-mic-app`）用同一支 RC003 在 macOS 上做「遥控器当无线麦 + 按键映射」，含 6 步向导、按 App 自动匹配键位、本地统计页（[部署教程](https://macin.top/posts/aef60ddf/)）。**【推断】** 其 Windows 版是时间问题，护城河必须建在 **Windows 稳定性 + Smart Focus + 零配置安装** 上，而不是「遥控器」这个点子。

## 4. 元数据成就系统（不保存文字的习惯循环）

**结论：只统计「发生了多少」，永不统计「说了什么」。元数据用来驱动回访与配置优化，不是制造虚荣数字。**

**可采集（全部本地，计数/时长/进程名，无文本）**：会话次数、总时长、平均与最长单次；累计字数**区间**（用户主动开启估算，按时长 × 语速常数推算，不读转写结果）；连续使用天数；按前台进程 Top 5（进程名是元数据，非内容）；**触发成功率**（按下→上屏成功的比例）与失败原因分布（驱动/焦点/超时）；「省下的时间」＝估算字数 ÷ 打字速度（默认 40 字/分钟，可改）。

**设计要点**：① 成就只在「回到 App」时出现，不弹系统通知；② 触发成功率同时给用户与自己看，作为北极星之一；③ 分享图默认关闭，必须用户主动生成。**风险（写进产品原则）**：① 字数/时长会变成虚荣指标 → **不做排行榜、不做连续天数惩罚、不把字数当付费门槛**；② 元数据仍是行为数据 → **本地存储 + 一键清空 + 默认不上报**；③ 进程分布会暴露用户在用什么软件 → 分享图**默认脱敏**，只显示类别（编辑器/浏览器/IM）。

## 5. 配置摩擦：把 N 步压到 1 步或 0 步

**结论：优秀 Windows 工具的共同做法是「安装器一次做完系统级动作 + 首启探测即修复」，而不是写更长的教程。**

**可借鉴的既有做法（有来源的事实）**
- **安装器顺带装驱动并负责卸载**：SayAll 的安装包在装 App 的同时检查并安装回环音频设备，另提供 `Uninstall ... .pkg` 移除驱动（[部署教程](https://macin.top/posts/aef60ddf/)）。Windows 等价物＝安装器内置 VB-CABLE 静默安装任务 + 卸载器清理驱动。
- **分发合规可行**：VB-CABLE 是 Donationware，官方允许与你的应用一起分发甚至静默安装，条件是用户能识别它是 VB-Audio 的产品并有机会付费（注明 vb-cable.com），规模大时建议支付授权费；但 VB-CABLE A+B / C+D 不允许捆绑分发。商店单价 **$5**，批量 10 个 $4.17 / 100 个 $3.61（[VB-Audio 商店](https://shop.vb-audio.com/zh/windows-/11-vb-cable.html)；亦见配套技术报告所引官方 licensing 页）。
- **每步都有「通过标准」**：SayAll 把链路拆成 6 个可勾选检查项（选语音工具 / 三项权限 / 收到实体按键 / 选兼容麦克风 / 亲自说一句 / 试三个普通按键），逐项给出通过标准（同上）。
- **首启探测即修复**：探测到已有可用回环设备就保留，缺失或不可用才安装/更新（同上）。**【推断】** Windows 侧＝已有 CABLE / VoiceMeeter / 其他虚拟声卡就自动选中并跳过驱动安装。

### 三类摩擦的降步方案
**① 装 VB-CABLE（现：下载→解压→右键管理员→确认→重启）**
- **1 步**：安装器内置官方包 + 静默安装 + 自动重启**音频服务**（`net stop/start Audiosrv`）替代系统重启；若必须重启，则「先以免驱动模式可用，重启后自动切到标准模式」。
- **0 步**：只有用户主动选「高保真模式」才装驱动；默认走免驱动（§6）。
- **兜底**：安装失败自动降级免驱动 + 首页「稍后修复」卡片，不阻塞向导。

**② 输入法快捷键对齐（现：用户自行去输入法设置里找快捷键再抄进本 App）**
- **1 步**：内置常见输入法/工具映射表（微信输入法、豆包输入法、Win+H、Typeless 等），向导只需**选「你装的是哪个」**；不确定时提供「逐个试一下」，自动发送候选键，用户只回答「出字了吗」。
- **0 步**：检测到已知输入法在前台时自动套用其推荐触发方式（如豆包 → 长按右 Alt）。【推断】只需进程名匹配，不读任何文本。
- 手动兜底保留：快捷键输入框 + 「按下你要用的组合键」录制。

**③ 输入目标学习（现：用户要理解「输入目标」概念并手动记录）**
- **1 步**：把「记录输入目标」从用户动作改为**自动动作** —— 首次在某应用成功上屏后自动保存；仅在失败时提示「要不要为微信记录一次输入框位置」。
- **0 步**：Smart Profiles 预置常见应用模板（浏览器地址栏/微信/QQ/Word/VSCode/终端），失配时才要求重录。
- **可视化**：HUD 常驻「输入目标指示灯」（绿=已锁定 / 橙=未识别但可尝试 / 红=已丢失，一键重录）。

## 6. 免驱动模式评估（关键假设）

**结论：足以服务大部分日常场景，能消除「管理员 + 重启 + 选设备」这组最硬摩擦；但不应作为默认，最佳定位是「体验模式 + 驱动失败兜底」，并在 UI 明示房间声音会被采集。**

**机制**：不装虚拟声卡，遥控器只作**无线触发器**（蓝牙按键事件），按下时向目标输入法发送其语音快捷键，音频由电脑/耳机麦克风采集。

**收益**：配置步骤从「装驱动（管理员+重启）+ 输入法选 CABLE + 本 App 选 CABLE」≈ **3–5 步 → 1 步（配对遥控器）**；不触碰驱动层 → 无管理员权限、无重启、无驱动冲突、卸载干净；同时规避虚拟声卡链路中真实的采样率错配故障（配套技术报告已记录同类设备要求两端采样率一致）。

**代价**：① **音质** —— 从「嘴边 15–25 cm 的指向麦」变成「桌上/耳机麦」，远场信噪比更差，嘈杂环境识别率下降（降幅需实测）；② **隐私观感** —— 采集范围从「遥控器附近」扩大到「整个房间」，会录到同事/家人对话，**这不违反现有隐私原则**（仍不读转写文字、不上传、不落盘），但姿态更弱，UI 必须写明并提供一键切回；③ **行为一致性** —— 「松开即停」依赖按键事件终止输入法会话，个别工具是「点按开始/再点按结束」（SayAll 就为 Typeless 做了「Fn 点按」模拟，见[部署教程](https://macin.top/posts/aef60ddf/)），需在预设里逐工具标注。

**呈现方式（【推断】）**：首次向导默认先跑免驱动，让用户在 5 分钟内拿到第一段文字（**体验模式**）；达成首次成功后引导切换到**标准模式（推荐）**；设置页保留「标准 / 免驱动」二选一并说明音质与隐私差异；驱动安装失败时**自动兜底**。安静独处或耳机麦质量好时免驱动已足够；开放办公室、会议、客厅必须用标准模式（遥控器近场麦）。

## 7. 商业化：不能靠什么收费，以及可行的路

**结论：唯一有结构性护城河的付费点是「硬件 + 服务 + 企业交付」；软件功能层的付费墙必须避开转写、数据与稳定性。**

**不能收费的东西（硬边界）**：① **转写能力本身** —— 微信/豆包/讯飞/Win+H 自带免费语音，本产品不拥有 ASR，按 token 收费在架构上不成立；② **数据与隐私** —— 不能上传/保存/分析转写文字，因此「用量计费 / 学习你的写作风格 / 云同步历史」这类主流计费锚点全部不可用；③ **云端依赖** —— 单机形态没有座位级 SaaS 的收费面；④ **稳定性与核心链路** —— 连接稳定性、焦点恢复、驱动安装、自检属基础体验，做成付费墙会摧毁口碑与开源信任。

| 模式 | 具体形态 | 真实参照 | 可行性 |
|---|---|---|---|
| **开源核心 + 付费增强** | 免费版含完整链路与全部稳定性能力；付费版＝高级 Profile/自动化/批量部署 | VoiceInk（GPL v3 开源 + **$25/39/49 一次性授权**，200k+ 下载、4.9 分；[官网](https://tryvoiceink.com/)）、superwhisper（$8.49/mo、$84.99/yr、**$249.99 终身**；[评测](https://spokenly.app/blog/superwhisper-review)） | **高**：一次性买断在本品类被验证（VoiceInk 明确用「买一次，永久拥有」对抗 Wispr Flow 的 $12/mo） |

## 8. 硬件套装：单位经济模型（含假设）

**结论：单套可做到约 46–54% 毛利，真正的门槛不在毛利而在库存、质检人力与售后；硬件带来的信任与留存是本产品最稀缺的资产。**

**假设（均为【推断】，需以实际报价与试销数据校准）**：遥控器批量采购 45–55 元/台（官方零售 99、二手 60–70）；蓝牙适配器（仅台式机）10–18 元；包装 + 上手卡 + 分装人工 5–8 元；预配对与质检 8–15 分钟/套（按 30 元/小时 ≈ 4–8 元）；快递 5–8 元；退换损耗按售价 5–8% 计提；无线电发射设备销售备案等合规成本**未计入，需咨询**。

| 项目 | 低 | 高 |
|---|---|---|
| 成本合计（遥控器+包装+质检+快递） | **59 元** | **79 元** |
| 建议售价 | 129 元（引流） | 169 元（主推）/ 199 元（含适配器 + 优先支持） |
| 毛利（未计退换） | 约 **54%** | 约 **53%** |
| 计入 8% 退换损耗 | 约 **50%** | 约 **46%** |

- **盈亏平衡**：【推断】固定投入（首批备货、包装设计、质检工位、摄影与详情页）按 2 万元、单套毛利 80 元算需 **250 套**；月销 100 套约 2.5 个月回本。
- **卖硬件 vs 卖软件（【推断】）**：**信任** —— 实体交付显著削弱「开源玩具」疑虑，付费用户更愿意反馈问题；**留存** —— 硬件在物理世界持续可见，天然降低卸载概率，但也带来「驱动装不上＝退货」的压力，**预配对与质检必须做到开箱即用**；**风险** —— 库存占用现金流、退换客服消耗维护者时间、遥控器停产改版会让配置方案失效；**纪律** —— **不承诺「终身免费」「保证识别准确率」**（后者由第三方引擎决定，本产品无法控制）。

## 9. 免费版 vs 付费版功能边界建议

**结论：免费版必须「完整、可用、体面」；付费版卖的是「省时间、省管理、要保证」，不是「解锁基本功能」。**

| 能力 | 免费版 | 付费版 | 为什么这样切 |
|---|---|---|---|
| 录音桥接链路、稳定性修复、Smart Focus、HUD、按键映射、基础 Profiles、自检与脱敏诊断、统计页 | ✅ 全部 | ✅ | 基础体验，付费墙会摧毁开源信任与口碑 |
| 免驱动 / 标准模式切换 | ✅ | ✅ | 配置摩擦是留存第一杀手，不能收费 |
| 内置 Profile 模板库 | ✅ 基础若干 | ✅ 全部 + 持续更新 | 卖「持续维护的内容」，不卖准入 |
| Profile 导入导出 / 本地分享 | ✅ | ✅ | 社区方案是留存引擎，必须免费 |
| 高级自动化（按进程/时间段/外设状态切换整套配置、联动系统动作） | ❌ | ✅ | 效率增强，不影响基础可用性 |
| 配置版本历史与一键回滚点 | ❌ | ✅ | 高级用户痛点，与更新通道付费点天然结合 |
| 更新通道 | GitHub Releases 手动 | 稳定通道 + 签名构建 + 更新前回滚点 | 成本低、感知强、不伤害免费用户 |
| 多设备授权 | 单机 | 多机 | 硬件套装/家庭用户自然需求 |
| 企业批量：MSI/静默部署、组策略预置、集中配置分发、审计日志（仅事件与配置） | ❌ | ✅ | B 端真实付费点，完全不触碰文本 |
| 优先支持 / SLA | ❌ | ✅ | 服务型收入，边际成本可控 |
| 预置行业词表/提示词包（**仅作为给第三方输入法的配置建议，本产品不处理文本**） | ❌ | ✅ | 卖配置知识与维护，不卖转写能力 |
| 转写、转写历史、写作风格学习、跨设备同步、用量计费 | ⛔ 永不 | ⛔ 永不 | 违反隐私原则与架构（无 ASR、无云、不读文本） |

**开源精神说明**：付费项都应是**本仓库可直接自行构建**的能力，或明确标注为「构建产物与服务的付费」（签名、托管更新、企业打包），代码不设技术封锁 —— 与 VoiceInk（GPL v3 开源 + 一次性授权，[官网](https://tryvoiceink.com/)）一致，是被验证过的模式。

## 10. 竞争定位与信息传达

**结论：中国市场最有效的是「省钱 + 省事」，海外开源社区最有效的是「本地、开源、可审计」。三组口号：**
1. **成本/替代（最打动中国用户）** —— 中：**「六十多块钱的遥控器，替你省掉每月 15 美元。」** 英：**"A $9 remote instead of a $15/month subscription."**
2. **隐私/架构（最适合海外开源社区）** —— 中：**「不读、不存、不上传：你的文字从来没离开这台电脑。」** 英：**"Open source, no cloud, no account — your words never leave your machine."**
3. **形态/体感（最适合短视频传播）** —— 中：**「手不离键，眼不离屏：按住说话，松开就出字。」** 英：**"Hold, speak, release. Type without touching the keyboard."**

**【推断】选择建议**：国内电商与短视频用第 1 组（价格对比冲击力最强，且自然带出硬件套装）；GitHub / Hacker News / Reddit 用第 2 组（该社区对「开源 + 无云 + 可审计」付费意愿最高，也是 VoiceInk、Tabularis 类项目的主要起量渠道）；第 3 组用于产品页首屏与演示视频，承担「三秒讲清是什么」。
**最容易被误解/质疑的三点与回应框架：**
1. **「录音会上云吗？会议内容安全吗？」** —— 先讲**架构事实**而非承诺：音频只在本机从遥控器流向虚拟声卡，由用户自选的第三方输入法处理；本产品不读、不存、不上传转写文字，诊断包默认脱敏。关键动作：官网首屏与向导第 1 屏就给出这句话，并提供「自检页 → 导出脱敏诊断」的可验证路径；**用「你可以自己验证」，不用「我们承诺」**。
2. **「为什么不用手机？手机也有语音输入。」** —— **手机解决「不在电脑前」，本产品解决「在电脑前但不想碰键盘」**；手机说完还要跨设备搬运，本产品直接把文字落在当前光标处；手机需拿起、解锁、切输入法，遥控器只需按住一个键，且不占屏幕 —— 会议/演示/沙发场景下这是决定性差异。
3. **「跟输入法自带语音有什么区别？我直接按 Fn 不就行了。」** —— 不否认引擎强，**本产品不加引擎，只加三样**：① 可离开键盘的物理触发键；② 输入目标锁定/恢复（解决焦点漂移把字写进错误窗口）；③ 按应用切换整套键位与配置。一句话：**「输入法负责听懂，我们负责让它在任何窗口、任何姿势下都能稳定落字。」**
