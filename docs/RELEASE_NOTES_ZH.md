# 言灵 · Vibe Flow Remote v1.2.1 更新说明

**定位：用户友好稳定版 · 2026-08-28**

本轮删掉无法稳定映射的能力，把录音回到首个正式版已验证路径，并修复“松开后才弹出麦克风”“再次打开第二个麦克风”和“TV 只闪一下”三个核心问题。

## 重点更新

### 1. 录音回到稳定按住模式

- 捕获组件完整回滚到已发布并长期验证的 `v1.0.3` 录音内核；当前 UI、自检和按键功能保持 `v1.2.1`。
- 微信输入法默认恢复为 `Ctrl + Win`、单击切换、`80 ms`。
- 按住录音键后由 RC003 的自然 ATVV 音频流开始收音，松开后由遥控器流停止事件结束。
- 输入桥接继续去重实体 DOWN/UP；捕获端拒绝重复开始和过期结束。
- 当前稳定单段最长约 `60 秒`，到达 RC003 物理边界后正常结束，不做自动续接。
- 已删除后续版本中的 `LONG DICTATION`、`MIC_EXTEND`、强制松开关闭和分段续接状态机。
- 转译由所选语音工具直接写入当前焦点输入框，不使用剪贴板或自动粘贴回填；开始前必须先单击目标输入框。

稳定音频参数没有变化：

| 参数 | 值 |
| --- | --- |
| 稳定档案 | `v11` |
| 增益 | `1.0x` |
| 处理 | `speech` |
| 尾音排空 | `180 ms` |
| 播放端 | `CABLE Input` |
| 工具读取端 | `CABLE Output` |

### 2. 四个方向键成为自定义入口

上、下、左、右分别支持一个动作。下拉列表只保留已验证的标准键盘动作，可立即测试、禁用或恢复原方向。本版新增“系统 · 区域截图”，发送 Windows 原生 `Win + Shift + S`。开机、返回和独立音量键不再生成映射。

![区域截图配置](images/03-shortcuts-screenshot.png)

### 3. TV 使用持久任务视图

TV 现在发送 `Win + Tab`，进入 Windows 任务视图后保持显示：

- 上下左右：移动选择；
- 确认键：进入所选程序；
- 再按 TV：关闭任务视图；
- 30 秒无操作：安全关闭，不意外切换。

### 4. 白天与夜间模式

- 默认白天模式沿用 v1.2 之前的白色基调。
- 夜间模式使用中性深灰和低饱和状态色，降低紫色与高亮刺激。
- 两种主题都保留真实按键高亮和录音波纹；没有真实音频时波形不动。

### 5. 教程与发布门禁

- 第 9 步改为配置四个方向键。
- 教程明确目标文本框必须真正获得焦点。
- 删除应用启动、网址打开、独立音量和返回键等未验证宣传。
- CI 固定检查 schema `25`、onboarding `8`、稳定微信档案和方向键映射集合。

- 主程序、捕获组件和按键桥接版本均为 `1.2.1.0`

## 真机发布门槛

1. 连续 100 次真实按住/松开，无重复启动或重复结束。
2. 提前松开立即结束；到约 60 秒边界自然结束。
3. 聚焦文本框时文字由语音工具直接写入；不经过剪贴板。
4. 全程无第二个麦克风会话。
5. TV 任务视图保持显示，四方向与确认键可操作。
6. 蓝牙重连、睡眠唤醒和应用重启后恢复。

所有公开版本都在 [版本下载页](VERSION_ARCHIVE_ZH.md) 保留固定 EXE、ZIP 与 SHA-256 入口，方便升级、回退和问题复现。
