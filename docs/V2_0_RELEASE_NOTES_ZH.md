## 本候选版更新

### 候选版 3 相对候选版 2 的变化

- **语音工具收敛为三个**：只提供 微信输入法（默认，`Ctrl + Win` 单击切换）、网易八哥说（右 Alt 单击切换）和其他语音工具（默认右 Shift 单击切换）。Typeless、Windows 语音输入、讯飞输入法、搜狗输入法和豆包输入法已下线；旧配置中保存的退役值会在加载时迁移为微信输入法并显示一次迁移提示。
- **开机自启修复**：注册表写入、回读、删除和安装器现在共用同一个值名，候选版 2 里“开机自启关不掉、关掉后重启又被注册”的问题不再出现。
- **可选 VB-CABLE 驱动包**：发布构建不再要求仓库中存在未跟踪的 VB-CABLE 包；包缺失时只输出 `VB-CABLE bundle: absent` 并继续，安装时由 `Install-VBCable.ps1` 在线下载官方包并按固定哈希校验。
- **更新器自测覆盖**：主机自测覆盖更新器的 GitHub-only HTTPS 白名单（含恶意主机负例）、版本解析、`SHA256SUMS.txt` 读取和资产查找；真正联网的下载与校验仍需已发布版本才能端到端验证。
- **脚本与源码 UTF-8 BOM 修复**：含中文的 PowerShell 脚本、安装器脚本和含非 ASCII 的 C# 源码补上 UTF-8 BOM，在英文 Windows 上不再因按 ANSI 代码页解码而解析失败；冻结的 `scripts/VibeMicAtvvCapture.cs` 有意保持逐字节不变。
- **生命周期验收结果**：干净安装 → 组件校验 → 卸载、未配置干净安装 → 卸载、V1.5 → 候选版升级 → 二次升级 → 卸载，三条均在本机用最终发布产物通过。
- **发布面**：安装包未签名，Windows 会显示“未知发布者”；请在 SmartScreen 提示中点「更多信息」→「仍要运行」，并核对随包 `SHA256SUMS.txt` 中的 SHA-256。

### 1. 目标输入框和 Smart Focus

- 可以为 ChatGPT、浏览器、编辑器、终端等应用学习可编辑输入控件。
- 保存前必须立即测试；未验证的目标不会被标记为当前目标。
- 描述符只保留进程和控件识别信息，不保存输入框文字、窗口标题正文或屏幕坐标。
- 用户刚刚手动点击的有效输入框优先；录音过程中不弹窗、不抢焦点。

### 2. 录音与语音反馈

- 继续使用 V1.5 的按住录音、松开结束行为。
- 语音页显示最近一次真实收音电平，帮助区分“声音太小”和“语音工具未唤起”。
- 录音结束只表示 Capture 已结束收音，不显示为“转写完成”。
- 松开录音键不自动按 Enter；用户必须检查文字并手动按确认键。

### 3. 快捷键和 Profiles

- 保留 V1.5 的 Profiles、实体键映射和键盘组合录制。
- 可配置键支持短按、长按、双击；没有独立配置的层会明确显示跟随关系。
- 录音键仍固定在稳定语音链路，不参与普通映射或手势层。
- 电源键可配置，但其扫描码与蓝牙重连后的麦克风键形态存在冲突，重视录音可靠性时建议保持不执行动作。
- 配置写入后等待 Bridge revision ACK，再显示已生效。

### 4. 首页、HUD、Deck 和自检

- 首页集中显示设备、语音桥接、Profile、目标和下一步。
- Live HUD 只显示可验证的状态，不把派发写成外部完成。
- Context Deck 为只读说明面板，不执行第二次遥控器动作。
- 自检结果包含证据、原因、影响、错误码、修复入口和重新检测。

### 5. 首次设置

统一为五项任务：了解流程、连接遥控器、准备音频、选择语音工具、完成个性化。允许稍后处理并保留进度，不以点击按钮冒充硬件通过。

## 语音工具边界

- 本候选版仅集成微信输入法、网易八哥说和其他语音工具；讯飞语音输入法、搜狗输入法和豆包输入法已从集成中移除，不会出现在「语音」页或首次设置中。旧配置中的任何退役值都会回退到微信输入法的稳定快捷键和触发方式，并显示一次迁移提示。
- 微信输入法部分版本会把识别结果放到剪贴板，属于第三方工具行为。候选版可能在目标已验证且收到真实完成回执后派发一次 `Ctrl+V` 兼容动作，但不保证所有目标都能成功粘贴；“粘贴动作已派发”不等于 AI 已收到。
- Typeless 和 Windows 语音输入不再作为 V2.0 的语音工具选项，保存的旧值会在加载时迁移为微信输入法并显示一次迁移提示。

## 稳定边界

- Capture 版本 `1.2.1.0`、录音内核 `v1.0.3`、`gain=1.0`、`speech`、`drainMs=180` 和约 60 秒设备边界保持不变。
- 不新增 MIC_EXTEND、自动续接、点击切换录音、自动 Enter、网页正文读取或任意脚本执行。
- 不读取、保存或上传普通转写文字，不自动发送 AI 消息。
- Notes Deck、便签 AI、Project Spaces、Capture & Ask 和 Browser Remote Lite 不属于当前主导航功能，不作为本候选版的交付承诺。

## 验证状态

自动化构建、源码契约、Host/Bridge/Capture 自检、候选附件哈希和本机 UI 资源检查已有证据；三条安装生命周期测试（干净安装 / 未配置安装 / V1.5 升级）也已在本机用最终发布产物通过。以下项目仍需目标设备人工验证，当前均标记为“未验证”：在**最终发布产物上说一句真实语音**并确认文字落点、一台**没有 VB-CABLE** 的机器首次启动、RC003 长时间按住/松开、设备级 F5 隔离、真实 VB-CABLE 回路、蓝牙重连/睡眠恢复、Windows 10/11 与一次性干净账户、125%/150%/200% DPI，以及第三方语音工具在实际 ChatGPT 输入框中的最终文字落点。**代码签名**同样未完成：安装包未签名，Windows 会显示“未知发布者”，签署与验证流程仍待补。
