# 言灵 Vibe Flow Remote 2.0.0 候选版

Release status: **candidate**。本文件用于候选评审，不代表已经创建 GitHub Release，也不代表正式稳定发布。

V2.0 在冻结的 RC003 按住录音链路之外，以首页为入口补齐“打开目标 APP、锁定目标、说需求、手动发送、查看结果、继续语音”的离键闭环。

## 录音键隔离现状（安装前请先读）

没有安装签名的设备过滤器之前，**录音键使用的是“遥控器在线范围内”的钩子隔离**，不是逐事件的设备归属隔离：

- 遥控器**已连接**时，F5 会被拦截，**不会**再去触发浏览器刷新或页面动作；
- 遥控器**不在线**时，普通键盘的 F5 **原样直通**；
- 用户态无法做到逐事件设备归属，因此它**不能与签名过滤器等同**。逐键真机矩阵与普通键盘 F5 隔离矩阵**尚未完成**。

安装后在「首页」「快捷键」「自检」三处都会显示当前状态徽章（`设备级精确隔离` / `Raw Input 安全直通`），首次设置向导第一步也会说明。

## 候选附件

候选构建同时生成以下三个文件；发布前必须以本批 `SHA256SUMS.txt` 核对：

- `VibeFlow-Setup.exe`
- `Vibe-Flow-Windows-x64.zip`
- `SHA256SUMS.txt`

当前构建未配置商业 Authenticode 签名。不要绕过 Windows 安全警告，也不要从非项目所有者提供的渠道取得候选包。

## 核心变化

- **Smart Focus**：学习、测试并验证可编辑 UI Automation 目标；验证失败或录音开始时安全停止。
- **Live HUD / Context Deck**：显示设备、语音、Profile、目标、项目和实体按键回执；窗口不抢录音焦点。
- **Capture & Ask**：当前窗口或区域截图、预览、复制并在目标验证后粘贴；不上传、不自动录音、不自动发送。
- **Browser Remote Lite**：展示推荐配置差异，由用户确认应用，并可一键撤销。
- **首次设置**：统一为五项任务；配置保存后等待 Bridge revision ACK 才显示按键服务生效。

## 稳定边界

- Capture 文件版本继续为 `1.2.1.0`，录音内核 `v1.0.3`。
- 按住录音、松开结束，RC003 单段约 60 秒。
- `gain=1.0`、`autoLevel=true`、`speech`、`drainMs=180`。
- 语音工具直接写入已聚焦输入框；Vibe Flow 不读取或保存普通转写文字。
- 没有 MIC_EXTEND、自动续接、点击切换、自动 Enter、AI 模型调用或网页正文读取。
- 开机、返回和独立音量键没有稳定 Windows 事件，不作为支持按键。

## 已验证与未验证

候选构建、组件自测、V2 专项测试、配置迁移、包内身份/哈希和本机 UI 流程已有证据。
