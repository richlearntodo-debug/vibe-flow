## 三、发布建议

**可以作为 `v2.0.0-rc`（公测）发布**，前提是下载页/发布说明里**显式写出录音键可能被前台应用收到**这一条（不要让用户自己发现）。

**转为正式稳定版前建议满足**
1. **签名**（或明确接受未签名并在下载页说明 SmartScreen 步骤）；
2. **一次真实机器的干净账户**安装 → 升级 → 卸载；
3. **一台没有 VB-CABLE 的机器**首启并确认降级路径（免驱动/trigger-only）可用；
4. RC003 隔离**要么实现、要么作为已披露限制被明确接受**；
5. 推分支让 CI 真正跑一遍（当前 CI 最后一次运行是 **2026-09-03**，之后所有改动都只在本机验证）。

## 四、如何复现上述验证

```powershell
# 全量链路（含界面矩阵 12 例 + 全部自测 + 打包）
.\BUILD_RELEASE.ps1

# 界面矩阵单独跑（三主题 × 四尺寸，逐例断言并保存截图）
.\scripts\check-ui-matrix.ps1 -KeepGoing -OutDir $env:TEMP\matrix

# 六页几何检查（可指定主题与强制窗口尺寸）
.\scripts\check-ui-geometry.ps1 -Exe .\VibeMic.exe -OutDir $env:TEMP\geo -Theme dark -ForceSize 880x500

# 崩溃记录端到端（会产生一份真实崩溃报告，验证后自行删除）
.\VibeMic.exe --ui-smoke --crash-test

# 面板/向导截图（深色请用启动时应用主题，运行中切换的截图可能抓到陈旧表面）
.\scripts\capture-ui-screenshots.ps1 -ProcessId <pid> -OutputDirectory $env:TEMP\shots -CaptureFullOnboarding
```

**注**：`--ui-theme <light|dark|system>` 与 `--crash-test` 是**验证专用**参数，正常使用不会用到。
