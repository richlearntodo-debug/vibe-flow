# 言灵 · Vibe Flow Remote V2.0 功能看板

V2.0 候选版以一条主路径为中心：**锁定目标输入框 → 按住说话 → 松开结束 → 检查文字 → 手动确认发送**。

[V2.0 下载](https://github.com/richlearntodo-debug/vibe-flow/releases/tag/v2.0.0-candidate.2) · [图文教程](V2_0_USER_GUIDE_ZH.md) · [FAQ](V2_0_FAQ_ZH.md) · [V1.5 稳定版](https://github.com/richlearntodo-debug/vibe-flow/releases/tag/v1.5.0)

## 能力总览

| 模块 | 当前能力 | 用户得到什么 |
| --- | --- | --- |
| 语音输入 | RC003 麦克风、按住说话、松开结束、真实收音状态 | 不离开键盘也能把需求说进当前输入框 |
| 语音工具适配 | 微信输入法、网易八哥说、讯飞语音输入法、搜狗输入法、豆包输入法和其他语音工具按各自客户端边界配置 | 可以选择已验证的语音工具，并在自检中区分工具和焦点问题 |
| Smart Focus | 学习、测试、验证可编辑控件，失败安全停止 | 少找窗口，避免把文字投到错误目标 |
| 快捷键与 Profiles | 保留 V1.5 映射，支持 Profile、短按/长按/双击和快捷键录制 | 方向键、确认、Home、TV、功能键可以按场景切换 |
| 应用控制 | 激活用户明确选择的本机应用，等待前台状态确认 | 快速回到当前输入应用，不执行任意命令 |
| Live HUD | 不抢焦点的状态反馈 | 看清设备、录音、处理和错误状态 |
| Context Deck | 只读的遥控器说明面板 | 查看当前 Profile、目标和实际动作，不执行第二次输入 |
| 自检中心 | 组件、蓝牙、音频、VB-CABLE、语音工具、Bridge ACK 和会话检查 | 知道哪里失败、影响是什么、下一步怎么修 |
| 首次设置 | 五项任务，支持保存进度和稍后处理 | 新用户知道先做什么，重启后能继续 |
| Smart Profiles | 默认关闭，可选按应用切换非语音动作 | 保留 V1.5 的开关、锁定和回退设置，不改变录音链路 |
| 主题和后台 | 浅色、深色、跟随 Windows、托盘和开机启动 | 日常使用不打扰，异常时仍有反馈 |

## 一句话工作流

```text
点击目标输入框或锁定 Smart Focus
  -> 按住 RC003 录音键说话
  -> 松开结束
  -> 等待语音工具处理
  -> 检查文字
  -> 按确认键发送一次
```

## 页面职责

| 页面 | 用途 | 不负责什么 |
| --- | --- | --- |
| 首页 | 看设备、语音桥接、Profile、当前目标输入框和下一步 | 不读取 AI 内容，不自动执行工作流 |
| 工作流 | 添加应用、学习输入控件、立即测试、设为当前 | 不用固定坐标点击，不读取窗口正文 |
| 快捷键 | 配置实体键、手势层、Profile 和组合键 | 不修改录音键，不替代 Bridge |
| 语音 | 选择工具、查看音频端点和收音电平 | 不提供普通用户修改冻结 Capture 参数的入口 |
| 自检 | 显示证据、错误码、影响、修复和重试 | 不把“已配对”夸大成“文字已输入” |
| 设置 | 外观、后台、隐私、本地数据、诊断与重置 | 不静默删除用户配置或共享驱动 |

## 可配置按键

| 实体按键 | 默认动作 | 配置边界 |
| --- | --- | --- |
| 录音键 | 按住收音，松开结束 | 固定稳定链路，不参与映射和手势层 |
| 上 / 下 / 左 / 右 | 标准方向 | 可绑定已支持的单击、长按或双击动作 |
| 中间确认键 | `Enter` | 可配置，但发送仍由用户确认 |
| Home | 显示桌面 | 可配置短按/长按，不自动覆盖现有行为 |
| TV | 任务视图 | 可配置，未验证的动作不标为成功 |
| 功能键 | 短按复制、长按粘贴 | 可分别配置短按/长按 |
| 电源键 | 未指派时交给 Windows | 电源键（VK 0xFF / 扫描码 E0 5E）提供配置入口，但与蓝牙重连后的麦克风键存在扫描码取舍 |

## 语音工具边界

- 微信输入法（默认）：稳定档案为 `Ctrl + Win` 单击切换；部分版本会把识别结果放入剪贴板，属于第三方行为，候选版可能在目标已验证且收到真实回执后派发一次 `Ctrl+V`，但不保证所有目标都能成功粘贴。
- 网易八哥说：默认用右 Alt 单击切换；按客户端要求确认快捷键和麦克风，Vibe Flow 不读取其转写文本，也不为它派发自动粘贴。
- 讯飞语音输入法：本候选版新增支持，默认快捷键为 `F6`、按住触发；请在讯飞输入法「设置 → 语音」把语音快捷键设为该组合并选择「长按说话」，应用里保存的快捷键与触发方式必须与它完全一致。
- 搜狗输入法：本候选版新增支持（本机安装于 `D:\SogouInput\16.6.0.4073`），默认快捷键为右 Ctrl、按住触发；请在搜狗自己的语音/按键设置里把语音输入快捷键设为右 Ctrl 并保持「按住说话」，应用与工具两边保存的值必须完全一致。
- 豆包输入法：本候选版重新提供（按用户要求恢复），默认快捷键为 `Alt + 空格`、按住触发，属于**支持但未验证**；两项历史风险仍未证实：①语音面板可能忽略模拟按键，遥控器可能唤不起它；②麦克风列表可能不提供虚拟声卡 `CABLE Output`。不要把它当作已验证路径。
- 其他语音工具：自定义启动/结束快捷键，默认右 Shift 单击切换；按客户端要求配置后自行验证。
- 免驱动模式：未检测到 VB-CABLE（没有采集进程）时，主机能自行唤起网易八哥说、讯飞语音输入法、搜狗输入法和自定义工具；微信输入法需要它自己的语音面板，因此仍需要 VB-CABLE。
- Typeless 和 Windows 语音输入：V2.0 不再作为可选语音工具；配置中的旧值会迁移为微信输入法并按名称提示用户。

## 稳定性边界

- Capture 继续为 `1.2.1.0`，录音内核为 `v1.0.3`；`hold`、`gain=1.0`、`speech`、`drainMs=180` 和约 60 秒设备边界不变。
- 没有 MIC_EXTEND、自动续接、点击切换录音、自动 Enter 或网页正文读取。
- Vibe Flow 不自研识别，不保存普通转写文字，不上传录音或截图。
- Smart Focus 保存的是目标描述符，不保存输入框文字、完整窗口标题、屏幕坐标或网页内容。
- 关闭 V2 新入口时，V1.5 映射、语音工具、Profiles、主题和后台设置保持不变。
- Project Spaces、Notes Deck、便签 AI、Capture & Ask 和 Browser Remote Lite 不属于当前主产品导航；历史文件仅作为归档，不应当作为当前下载包的功能宣传。

## 问题处理

先打开“自检”，再根据具体错误码处理蓝牙、音频、语音工具和目标焦点。文字进入剪贴板时，先确认是否使用微信输入法，再改用讯飞语音输入法做对照；不要让程序读取剪贴板文字回填。
