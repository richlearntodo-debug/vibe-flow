# 言灵 Vibe Flow Remote v1.3.0 候选版

这是快捷键定制与后台防冲突候选版，不替代已经发布且稳定的 `v1.2.1`。录音捕获仍使用原样保留的 `v1.0.3` 内核，增益、音频路由、微信输入法触发和约 60 秒物理边界均未调整。

## 本轮新增

- 首次设置从 11 个技术步骤合并为 5 项用户任务，保存进度并支持 VB-CABLE 重启后续接。
- 四方向、确认、TV 均可单独配置；Home 短按和长按、功能键短按和长按可分别配置。
- 支持选择正在运行或已安装的应用、打开 HTTPS 网页、编辑动作、系统动作、媒体动作、区域截图和自定义快捷键。
- 本机应用按“真实聚焦运行窗口 -> 有效 EXE -> Windows 开始菜单 AppID”三级执行；只有目标窗口成为前台才报告成功。
- 已运行 APP 切换失败时会明确报错，不再继续启动 EXE 造成重复实例；全新候选包也会按 Host 契约携带正确命名的冻结 Capture。
- 开机键不再生成运行时映射；升级时会把旧开机键 APP/网页动作迁移到空闲的 Home 长按。
- 主程序已启用 Windows Per-Monitor V2 DPI awareness，并在高缩放下限制窗口到当前工作区；当前已完成 100%/96 DPI 截图，125%/150%/200% 仍是发布前实机门禁。
- 快捷键页提供通用导航、Vibe Coding、媒体控制三套简单方案，不包含宏或自动 Profile。
- 配置页按实体遥控器位置排列，使用中央遥控器示意图、实体键识别、实时高亮、独立测试和恢复默认。
- “测试”会等待按键桥接返回真实执行结果；应用不存在、地址无效或桥接超时会明确显示失败，不再只提示“已发送”。
- 非录音动作只由带设备身份的 RC003 Raw Input 或专属过滤通道执行。普通键盘的 `` ` ``、Home、菜单键、Enter 和方向键不会再触发遥控器映射。
- 没有签名过滤驱动时自动使用“Raw Input 安全直通”：配置动作可以执行，普通键盘不被接管，但遥控器原始键的系统效果可能同时发生；UI 和自检会明确显示这一边界。
- 设置页支持白天、夜间和跟随 Windows；支持配置备份、导入和恢复上次，导入不会改变冻结语音档案。
- 诊断导出会隐藏用户目录、电脑名、设备路径、地址、URL 和应用目标。

## 五项首次设置

1. 确认 Windows、RC003 和按住说话方式。
2. 配对 RC003，并收到一次新的真实方向键事件。
3. 检查或安装 VB-CABLE，并确认遥控器麦克风和本地音频端点。
4. 选择语音工具、核对快捷键，并完成一次真实文字回填。
5. 保存开机启动、自动连接和托盘行为，查看最终汇总。

完整截图与零基础说明见 [v1.3 图文教程](V1_3_USER_GUIDE_ZH.md)。

## 为什么不直接照搬参考项目

参考项目在 macOS 上可以使用 IOHID 与系统事件权限完成设备级处理。Windows 的全局键盘钩子本身不提供设备身份，因此只看 `VK` 和扫描码会把实体键盘 `` ` `` 与遥控器 TV 键混为一谈。

旧候选版曾将低层 Hook 与 RC003 Raw Input 做短窗口配对。真机日志证明这条路线存在循环依赖：Hook 为了等待设备身份先拦截事件，而 Windows 在事件被拦截后不再投递相应 Raw Input，于是 UI 测试可以成功，实体遥控器映射却没有进入执行器。

当前候选版改为两条明确通道：有签名设备过滤器时，由过滤器完成精确拦截与执行；没有过滤器时，低层 Hook 放行所有非录音候选，由能识别设备的 Raw Input 独立执行动作。录音键不经过本轮新逻辑，继续使用已经验证的 V1.2.1 专用状态机。完整证据与架构边界见 [按键路由根因报告](V1_3_INPUT_ROUTING_ROOT_CAUSE_ZH.md)。

## 实体键支持边界

Home 已有稳定键盘报告，支持短按和长按。开机、返回和独立音量加减在当前 Windows 蓝牙栈中没有稳定上报，因此不提供配置入口，也不作为候选版能力宣传。未来只有在多台真机能够重复捕获对应报告后才会开放。

## 真机验收

1. 只运行候选目录中的一个实例，不覆盖正式安装目录。
2. 保持程序在后台，在实体键盘连续输入 `` ` `` 20 次，必须全部得到原字符，不得打开任务视图；健康文件中的普通键盘动作计数不得增加。
3. 在实体键盘测试 Home、菜单键、Enter 和四方向，必须保持 Windows 原行为。
4. 遥控器 TV 必须打开任务视图；方向键移动选择，确认键进入。
5. 将四个方向分别配置为复制、粘贴、区域截图和打开网页。卡片右侧“测试”只验证执行器；随后必须用实体遥控器逐项验证，并确认 `raw_action_edges` 增加。
6. 从“正在运行”和“已安装”各选择一个本机应用。第一次应打开，应用已有窗口时应切换到该窗口；重启应用后配置必须保留。
7. Home 短按和长按各执行一次；功能键短按和长按各执行一次，每个动作只允许触发一次。
8. 蓝牙断开重连、遥控器休眠唤醒、Windows 睡眠恢复后重复第 2 至第 7 步。
9. 完成 100 次录音按下与松开，并完成一次约 60 秒边界测试；不得出现双麦克风、剪贴板回填或语音参数变化。

任一来源保护或实体动作闭环测试失败时，候选版不得发布。无签名过滤器的候选包不得宣传为“无副作用精确拦截”；请保留 `input-bridge-log.txt`、`input-bridge-health.json` 和“导出诊断”结果用于定位。
