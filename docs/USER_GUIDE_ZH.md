# 言灵 · Vibe Flow Remote 使用教程

这份教程面向第一次使用 RC003 蓝牙语音遥控器的 Windows 用户。正常情况下，完成一次设置后，以后只需要聚焦输入框并按住录音键。

> **第一次安装：先下载 [`VibeFlow-Setup.exe`](https://github.com/richlearntodo-debug/vibe-flow/releases/latest/download/VibeFlow-Setup.exe)。** 不要下载 GitHub 发布页底部的 `Source code (zip)` 或 `Source code (tar.gz)`，它们是给开发者使用的源码，不是 Windows 安装包。

## 按你的情况开始

| 你的情况 | 从这里开始 |
| --- | --- |
| 第一次安装 | [下载与安装](#下载与安装)，然后依次完成页面上的五步设置 |
| 已经安装旧版 | 直接运行最新版安装包覆盖升级，再做一次[两分钟验收](#两分钟验收) |
| 能打开但不能听写 | 先运行[连接与自检](#连接与自检)，再按现象查看[常见问题](#常见问题) |
| 只想确认按键 | 查看[按键快捷方式](#按键快捷方式) |

## 先看完整流程

首次配置只做五件事：

```text
选择转写工具 -> 安装 VB-CABLE -> 连接 RC003 -> 核对快捷键 -> 完成首次听写
```

每一步都以页面上的绿色状态为完成标准。遇到黄色或红色提示时，先点击提示旁边的操作按钮，不需要自行修改注册表、蓝牙服务或音频驱动。完成配置后，日常使用只有三步：点击要输入文字的位置、按住遥控器录音键说话、松开后等待文字回填。

言灵是 Windows 10/11 x64 桌面程序，不是 Android 应用，也没有 APK。普通用户优先下载安装版，不需要下载源码或运行构建命令。

## 使用前准备

请先确认：

- Windows 10/11 电脑具有蓝牙功能。
- 遥控器型号为 RC003 / MI RC，带麦克风录音键。
- 准备使用至少一种语音转文字工具；微信输入法、Typeless、Windows 语音输入和 Voquill 均可配置。
- 能够安装 VB-CABLE；这是当前架构唯一必须额外安装的本地驱动，首次向导会提供官方入口和自动检测。

## 下载与安装

只从 [GitHub Releases](https://github.com/richlearntodo-debug/vibe-flow/releases/latest) 下载正式发布文件。发布页的 **Assets** 区域中只需要关注下面三个文件：

- **推荐：`VibeFlow-Setup.exe`**。双击后按安装向导完成安装，程序会出现在开始菜单和 Windows“已安装的应用”中。安装器按当前用户安装言灵本体，不需要管理员权限，也不会覆盖升级前的 `vibe-mic-config.json`。
- **免安装：`Vibe-Flow-Windows-x64.zip`**。完整解压到固定目录后双击 `VibeFlow.exe`，不要直接在压缩包内运行。
- **校验文件：`SHA256SUMS.txt`**。用于确认下载文件完整且没有被替换。

不要下载 GitHub 自动附加的 `Source code (zip)` 或 `Source code (tar.gz)`。它们不包含可直接使用的完整 Windows 发布环境，也不适合普通用户安装。

发布页同时提供 `SHA256SUMS.txt`。如果 Windows 显示来源提示，请先确认文件来自本仓库，再核对 SHA-256。言灵安装器尚未进行商业代码签名；VB-CABLE 是独立的虚拟音频驱动，其官方安装过程会单独请求管理员权限。

首次打开会自动进入五步设置。现有用户安装新版本时可以直接覆盖升级，原有转写工具、快捷键、开机启动与声音设置都会保留。

## 第一步：选择转写工具

首次向导先询问你日常使用的语音转文字工具。言灵只负责把遥控器音频送过去，识别、结构整理和账号服务仍由所选工具负责。

| 工具 | 推荐快捷键 | 触发方式 |
| --- | --- | --- |
| 微信输入法 | `Ctrl + Win` | 工具栏优先，快捷键作为回退 |
| Typeless | `Right Alt` | 单击开始，再单击结束 |
| Windows 语音输入 | `Win + H` | 单击开始，再单击结束 |
| Voquill | `Ctrl + Win` | 按住开始，松开结束 |
| 其他语音工具 | 自定义 | 可选单击切换或按住触发 |

选择后，页面会显示客户端是否正在运行、推荐配置和对应的官方安装或设置入口。此步骤还可以选择“登录 Windows 后自动启动言灵”；只有用户主动勾选后才会写入开机启动项。

![支持的转写工具](images/06-transcription-tools.png)

不知道选哪个时，可以按下面的顺序判断：

- 已经使用微信输入法，并希望保留它的中文识别和结构整理：选择“微信输入法”。
- 已经订阅或日常使用 Typeless：选择“Typeless”。
- 不想安装额外的转写客户端：选择“Windows 语音输入”。
- 已经安装 Voquill：选择“Voquill（开源）”。
- 目标客户端支持全局启动快捷键，但不在列表中：选择“其他语音工具”。

### 微信输入法

1. 先启动微信输入法，确认任务栏或工具栏上的麦克风可以用鼠标打开。
2. 在言灵中选择“微信输入法”，保留“单击切换”。
3. 默认填写 `Ctrl + Win`；言灵会优先调用已验证的微信工具栏麦克风，快捷键只在工具栏入口不可用时回退。
4. 点击“测试所选工具”。面板能出现并自动结束，才进入下一步。

若你的微信输入法使用其他快捷键，应以微信输入法当前设置为准，并把相同快捷键填入言灵。

### Typeless

1. 安装并登录 Typeless，先用键盘完成一次正常听写。
2. 在 Typeless 设置中确认全局听写快捷键；常见默认值为 `Right Alt`。
3. 在言灵中选择“Typeless”，填写相同快捷键，触发方式选择“单击切换”。
4. 点击“测试所选工具”，确认第一次按键开始、第二次按键结束。

Typeless 快速开始可从言灵的“获取所选工具”打开，也可查看 [Typeless 官方首次听写指南](https://www.typeless.com/zh-cn/help/quickstart/first-dictation)。

### Windows 语音输入

1. 不需要安装额外转写客户端。先点击任意输入框，手动按一次 `Win + H`，完成 Windows 的首次初始化。
2. 在言灵中选择“Windows 语音输入”，保留 `Win + H` 和“单击切换”。
3. 点击“测试所选工具”，确认 Windows 语音输入面板可以打开和关闭。

语言、麦克风权限或系统语音设置异常时，点击言灵中的“检查麦克风设置”。

### Voquill 或其他工具

Voquill 当前开源 Windows 配置常用 `Ctrl + Win` 和“按住触发”，不同版本可能变化，必须以客户端设置为准。其他工具需要先设置一个全局快捷键，再把完全相同的按键和触发方式填入言灵。建议先用键盘验证客户端本身，再点击“测试所选工具”。

言灵不会安装、登录或破解任何第三方客户端。第三方工具的账号、网络、识别质量、订阅和隐私政策由对应厂商负责。

## 第二步：安装本地音频通道

言灵需要 VB-CABLE 把遥控器音频交给所选转写工具。发布包不捆绑该驱动；如果向导已经检测到两个 CABLE 端点，可以直接继续，不必重复安装。

1. 从 [VB-Audio Cable](https://vb-audio.com/Cable/) 下载并安装 VB-CABLE。
2. 安装完成后按安装程序提示重启 Windows。
3. 回到向导点击“重新检测”，确认 `CABLE Input` 和 `CABLE Output` 都显示已检测。

```text
RC003 -> 言灵 -> CABLE Input（播放端）-> CABLE Output（录音端）-> 转写工具
```

建议保持“听写时自动使用遥控器麦克风”开启。每次听写开始前，言灵会临时把 Windows 的三个默认录音角色切换到 `CABLE Output`；音频排空后恢复原来的麦克风。关闭后，才需要在每个转写工具中手动选择 `CABLE Output`。

## 第三步：连接遥控器

1. 打开 Windows **设置 > 蓝牙和设备**。
2. 让遥控器进入配对模式。
3. 添加设备，选择 `MI RC` 或“小米蓝牙语音遥控器”。
4. 等待 Windows 显示“已连接”或“已配对”。

如果遥控器以前连接过电视或其他电脑，先断开旧设备，再重新配对。

回到向导点击“开始检测”。看到“已连接，可以使用”再继续。首次建立 ATVV 语音服务可能需要数秒；若一直停在连接中，按一下方向键唤醒遥控器后重新检测。

## 第四步：匹配快捷键

向导会自动填入所选工具的推荐快捷键和触发方式。它们必须与工具内部设置完全一致：

1. 在转写工具中确认或设置全局快捷键。
2. 回到言灵填写相同快捷键，并选择“单击切换”或“按住触发”。
3. 点击“测试启动与结束”。工具应开始听写，并在约一秒后自动结束。

这一步只验证工具控制，不发送遥控器音频。微信输入法路径会优先点击已验证的工具栏麦克风入口；工具栏不可用时才回退到 `Ctrl + Win`。

## 第五步：完成首次听写

1. 点击向导中的空白测试输入框，确保光标正在闪烁。
2. 按住遥控器录音键，说“测试麦克风，一二三四五六，期待效果”。
3. 说完后松开，观察“正在整理文字”状态。
4. 看到绿色“首次听写成功”并听到轻提示音后，点击“完成设置”。

成功判断来自本地会话状态，不依赖也不读取输入框中的文字。首页显示“已准备好”后，以后只需聚焦任意输入框并按住录音键。

## 两分钟验收

完成向导后，用下面四项确认整条链路，而不只是确认页面能打开：

1. 首页显示绿色“已准备好”，侧栏显示“语音链路就绪”。
2. 聚焦任意文本输入框，按住录音键时首页遥控器麦克风高亮，并显示“正在听写”。
3. 松开后先显示青色“正在整理文字”，随后文字由所选工具回填并播放完成提示音。
4. 打开“连接与自检”，确认七项全部通过；最近一次听写应显示响应时间、输出电平、蓝牙间隔、丢包、排空和麦克风恢复状态。

## 语音听写页面

“语音听写”页用于确认通道是否就绪，并查看上一段语音的时长与电平。

![语音听写页面](images/02-dictation.png)

- **转写工具**：选择微信输入法、Typeless、Windows 语音输入、Voquill 或其他客户端。
- **启动快捷键 / 触发方式**：必须与客户端设置一致。内置配置会自动带出各工具的常用默认值。
- **测试所选工具**：只验证客户端能否被快捷键或微信工具栏唤起，不验证遥控器收音。
- **声音处理**：默认“清晰增强”会稳定补偿轻声并限制孤立尖峰；“原始直通”用于排查未经增强的源音频。
- **收音灵敏度**：从 `1.0x` 开始，只有在距离较远或声音较轻时再小幅提高。
- **自动使用遥控器麦克风**：建议开启。言灵只在听写期间临时使用 `CABLE Output`，音频排空后恢复原来的 Windows 默认麦克风；意外退出时会在下次启动优先恢复。
- **稳定档案 v11**：发布版默认固定使用 `1.0x`、清晰增强、180 ms 排空和自动麦克风路由。修改高级音频参数后，自检会提示偏离，并可一键恢复。

## 按键快捷方式

言灵只展示已经通过 RC003 真机验证的单击和长按操作。

![按键快捷方式页面](images/03-shortcuts.png)

| 遥控器按键 | 默认行为 | 使用方法 | 是否可配置 |
| --- | --- | --- | --- |
| 录音键 | 语音听写 | 按住说话，松开后等待文字回填 | 固定 |
| 确认键 | `Enter` | 确认、发送或换行，取决于当前软件 | 可以 |
| Home | 显示桌面 `Win + D` | 再次按下可返回原窗口 | 可以 |
| 方向上 / 下 | 移动；系统音量回退 | 短按移动，长按上调高音量、长按下调低音量 | 固定 |
| 方向左 / 右 | 原生左右移动 | 在文本或菜单中移动；TV 打开任务切换后选择前一个或后一个应用 | 固定 |
| 功能键 | 打开或切回 ChatGPT 客户端 | 下拉可选择 DeepSeek、Claude、Cursor、VS Code、Windsurf 等客户端操作 | 可以 |
| TV | 打开任务切换器 | 按 TV 后用左 / 右选择应用，再按确认进入 | 可以 |
| 独立音量 + / - | 当前不支持 | 已验证 RC003 没有向 Windows 上报稳定事件，请长按方向上 / 下调音量 | 不显示 |
| 返回键 | 当前不支持 | 已验证 RC003 没有向 Windows 上报稳定事件 | 不显示 |

修改可配置项后点击“立即应用”。右侧遥控器会高亮当前配置项，并固定显示 Home、方向键、功能键和 TV 的默认操作。若你修改了某个可配置按键，实际行为以页面当前下拉选项为准。

## 连接与自检

遇到连接、按键或录音问题时，打开“连接与自检”。页面会自动运行本地检查，不要求用户理解技术日志。

![连接与自检页面](images/04-diagnostics.png)

建议按这个顺序排查：

1. 先看顶部通过数量和结论。绿色表示通过，黄色表示建议确认，红色表示必须修复。
2. 查看七个检查项：本地组件、VB-CABLE、稳定档案、后台桥接、RC003、转写工具、最近一次端到端听写。
3. 异常项点击右侧按钮。页面会直接前往对应的蓝牙设置、语音配置、官方驱动页面，或恢复稳定参数。
4. 修复后点击“重新自检”，再完成一次真实听写。最近会话会显示工具响应、输出电平、蓝牙间隔、丢包、排空和麦克风恢复。
5. 提交 Issue 时点击“复制问题摘要”直接粘贴；需要完整上下文时再使用“导出诊断”。
6. 若所有自检通过但识别仍差，点击“诊断下一段音频”，确认后说固定短句。言灵只保存下一段、最长 30 秒，并分别生成遥控器解码原声、处理后声音和 `CABLE Output`；完成后自动关闭采集。

正常运行记录和“导出诊断”文本不包含录音。“诊断下一段音频”生成的 WAV 只保存在本机 `remote-voice-session`，不要直接上传；先自行试听并删除不希望公开的内容、输入文字、蓝牙地址或其他个人信息。

## 偏好设置

![偏好设置页面](images/05-settings.png)

- **打开言灵后自动连接遥控器**：建议开启。
- **关闭主窗口后继续运行**：建议开启，言灵会留在系统托盘。
- **登录 Windows 后自动启动言灵**：按个人需要选择。
- **听写完成或失败时播放轻提示音**：默认开启，可随时关闭，也可点击“试听提示音”。
- **打开入门指南**：重新进入五步向导，不会清空现有按键和语音设置。

## 常见问题

先打开“连接与自检”，找到与你的现象最接近的一行：

| 现象 | 先检查 | 处理方法 |
| --- | --- | --- |
| 安装包或程序打不开 | 下载来源、SHA-256、Windows 来源提示 | 只从 Releases 下载；核对校验值。安装包尚未商业签名，确认发布者仓库后再运行 |
| 找不到 `CABLE Input` / `CABLE Output` | “连接与自检”中的 VB-CABLE 项 | 从页面打开 VB-CABLE 官网安装，按驱动提示重启 Windows，再点“重新自检” |
| 蓝牙显示已配对，但言灵一直连接中 | RC003 是否仍连接电视、是否休眠 | 断开其他设备，按方向键唤醒；仍失败时在 Windows 蓝牙中移除后重新配对 |
| 点击“测试所选工具”没有反应 | 客户端是否运行、快捷键和触发方式是否一致 | 先用实体键盘测试客户端，再把同一设置填入言灵 |
| 测试工具正常，但录音键无反应 | 后台桥接、RC003/ATVV 两项 | 按自检按钮重启桥接或打开蓝牙；修复后完成一次真实听写 |
| 转写面板打开，但没有文字 | 自动麦克风路由、两个 CABLE 端点 | 开启“听写时自动使用遥控器麦克风”；关闭时必须在客户端手动选择 `CABLE Output` |
| 首字丢失、松开后才启动或延迟很高 | 最近听写中的工具响应、排空和丢包 | 恢复“稳定档案 v11”，不要改启动延迟和 180 ms 排空；导出问题摘要 |
| 声音小、漏字或错字多 | 输出电平、蓝牙间隔、处理模式 | 先保持清晰增强与 `1.0x`，靠近遥控器说固定短句；仍异常时使用一次性音频诊断 |
| 所有普通按键突然失效 | 后台桥接、运行中的旧实例 | 从托盘完全退出后重开；确认诊断里的程序路径属于当前版本 |
| 独立音量键或返回键无效 | 无需重复配置 | 这是已验证硬件边界；音量使用长按方向上 / 下，返回键不宣称支持 |
| 更新后界面仍是旧版 | 程序路径和开始菜单入口 | 退出旧实例，从开始菜单打开安装版；免安装版运行新解压目录中的 `VibeFlow.exe` |

### 按录音键没有任何反应

先在“语音听写”页确认转写工具、快捷键和触发方式，再点击“测试所选工具”。如果测试也不能启动客户端，请先在客户端中设置相同快捷键并确保客户端正在运行。

如果手动测试正常、遥控器录音键无反应，打开“连接与自检”，按红色或黄色检查项的按钮处理，然后重新连接蓝牙。

按下录音键后，言灵先启动所选转写工具，再把 RC003 实时音频通过 VB-CABLE 送入该工具；松开后补充短暂静音并等待虚拟音频排空。微信路径优先点击已验证的工具栏入口，只有工具栏不可用时才回退快捷键，避免旧版固定等待约 1.2 秒造成首字延迟。若客户端未能启动，本次音频会被丢弃并写入诊断日志，不会在松开后延迟回放，也不会混入下一次听写。

### 能启动语音输入，但识别内容缺失

先确认“听写时自动使用遥控器麦克风”已开启，并在运行记录中看到 `DEFAULT CAPTURE ROUTE ACQUIRED` 与 `DEFAULT CAPTURE ROUTE RESTORED`。关闭自动路由时，必须在转写工具中选择 `CABLE Output`，不要选择电脑内置麦克风。保持“清晰增强”和 `1.0x`；环境噪声较大时调低，声音仍偏小时再逐步调高。不要直接拉到最大，过高增益会同时放大房间噪声和蓝牙编码噪声。

若仍然漏字，不要继续盲目提高增益。到“连接与自检”点击“诊断下一段音频”，按提示说固定短句，再依次试听 `01-raw-decoded-16k-mono.wav`、`02-processed-16k-mono.wav` 和 `03-cable-output.wav`，即可判断问题位于蓝牙解码、声音处理、虚拟声卡还是转写客户端。

### 为什么工具能打开，却听不到遥控器

这是旧方案最关键的根因：言灵把声音写入 `CABLE Input`，只代表音频到达 VB-CABLE 的播放端；如果转写工具仍监听电脑物理麦克风，它不会自动读取对应的 `CABLE Output`。当前版本在每次听写前临时把 Windows Console、Multimedia 和 Communications 三个默认录音角色都指向 `CABLE Output`，音频排空后恢复原设备，并保留崩溃恢复标记。因此建议一直开启“听写时自动使用遥控器麦克风”。

### Typeless 或 Voquill 没有反应

言灵只负责发送快捷键和音频，不会安装或登录第三方客户端。先启动客户端，确认使用键盘可以正常开始/结束听写，再把完全相同的快捷键和触发方式填入言灵。Typeless 的常见默认设置是 `Right Alt` + 单击切换；Voquill 当前开源 Windows 默认是 `Ctrl + Win` + 按住触发，若客户端版本不同应以客户端界面为准。

### 按键突然全部失效

在系统托盘中退出言灵后重新打开。如果蓝牙状态不是已连接，请在 Windows 蓝牙设置中先断开再连接遥控器。

### 更新后仍像旧版本

安装版请从开始菜单打开“言灵 Vibe Flow Remote”。免安装版请直接运行新目录中的 `VibeFlow.exe`。新版会通知其他目录中的旧实例退出并自动接管。诊断信息中的程序路径应当与当前目录一致；不要同时保留两套开机启动项。

### 返回键或独立音量键不能使用

在已验证的 RC003 Windows 蓝牙链路中，这些物理键没有上报可用事件。言灵不会伪装支持它们。系统音量请使用长按方向上/下。

### 为什么没有组合键

RC003 不稳定地同时上报功能键和第二个按键，容易造成误触或漏触。当前版本只保留经过真机验证的单击、顺序选择和长按功能。

## 隐私与卸载

言灵默认只在本机解码并转发音频，不保存录音，不提供云端转写，不读取转写工具产生的文字，也不向其他进程注入代码。只有用户明确确认一次性音频诊断时，下一段录音才会保存在本机，完成后自动关闭；第三方转写工具是否上传音频，取决于其自身隐私政策和用户设置。

安装版可在 Windows **设置 > 应用 > 已安装的应用** 中卸载“言灵 Vibe Flow Remote”。免安装版先在“偏好设置”关闭开机启动、从系统托盘退出言灵，再删除解压目录。VB-CABLE 是独立驱动，只有不再使用任何虚拟麦克风工具时才建议在“已安装的应用”中单独卸载。
