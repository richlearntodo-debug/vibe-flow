# V2.0 候选版已知限制

> 本文件只描述公开候选版 `v2.0.0-candidate.3` 的已知边界。未完成目标设备验证的项目不会写成“通过”。

## 发布与安装

- V2.0 是候选版，不是正式稳定版；V1.5.0 仍是推荐稳定版本。
- 安装包未配置商业 Authenticode 签名，Windows 可能显示 SmartScreen 或未知发布者提示。
- 干净账户安装、V1.5 升级、二次升级、卸载和用户数据保留仍需在目标环境完成完整验收。当前状态：干净安装、未配置安装与 **V1.5 升级（含配置保留与已下线工具的迁移）在本机与 CI 上均已通过** ✔（CI run `34755944510`）；目标设备（不同 Windows 版本/账户/杀毒环境）仍建议复验一次。
- 已发布的 `v2.0.0-candidate.3` 安装包与 ZIP 里的说明文档是发布时的快照：其中「快捷键动作选择」与「快捷键录制」两张对话框截图仍是 V1.5 画面。仓库（`main`）与下次候选包已换成出货构建重拍的版本。
- 高 DPI 的 125% / 150% / 200% 观感仍需要真实 Windows 设备人工检查；自动几何检查不能替代截图目视。

## RC003 和输入隔离

- 没有签名设备级过滤器时，录音键使用用户态的 RC003 在线范围隔离，不能做到逐事件设备归属。
- RC003 在线时，普通键盘的 F5 也可能被一并拦截；RC003 不在线时普通键盘 F5 会恢复直通。
- 这不是签名过滤器的等价替代。RC003 录音、普通键盘隔离、断连和重连必须在真实设备上分别验证。
- **电源键是普通映射键，不是录音键** ✔：本机当前三层的实际动作是**短按 = DeepSeek 用量页 URL** ✔、**长按 = Bilibili** ✔、**双击 = 任务切换器** ✔，所以按下电源键会执行它自己那一层的动作（可能导航或打开页面，属预期行为）✔。**动作要写在两个地方** ✗：Profile 映射（`vibe-mic-config.json` ✔）**和手势层覆盖（`UserData\gesture-layers.json` ✔，优先级更高 ✗）** —— 只改前者不生效 ✔。桥里的守卫 ✔：**动作全是 `none` 的映射一律视为未启用** ✔，且电源键的共用扫描码（`VK 0xFF` / 扫描码 `E0 5E`）**永不作为录音键候选** ✔ —— 因此**电源键不会开始录音** ✔。仍更看重录音可靠性时，可以把电源键（含短/长/双击三层）全部留空 ✔。
- Power、Back 和独立音量键的支持边界不同：Power 键可配置，但其扫描码与蓝牙重连后的麦克风键形态存在冲突；Back 和独立音量键没有稳定的用户态事件，不提供映射。重视录音可靠性时请保持 Power 为“不执行动作”。

## 语音工具和文字落点

- 当前仅提供微信输入法、网易八哥说和其他语音工具；讯飞语音输入法、搜狗输入法和豆包输入法已从集成中移除。旧配置中的任何退役值加载时都会回退到微信输入法稳定参数，并显示一次迁移提示。
- Vibe Flow 不自研识别，不读取、保存或上传普通转写文字，也不读取网页正文。
- 微信输入法部分版本会把识别结果放到剪贴板，这是第三方行为。候选版不保证微信输入法在所有 ChatGPT、浏览器、提权窗口中直写；兼容路径可能派发一次 `Ctrl+V`，但“动作已派发”不等于文字已落入或 AI 已收到。
- 网易八哥说的快捷键、麦克风和最终文字落点由其客户端决定，未在所有版本上验证；候选版不为它派发自动粘贴。
- Typeless 与 Windows 语音输入不再是 V2.0 的可选语音工具：Typeless 的默认快捷键曾与网易八哥说重复（选中 Typeless 实际触发网易八哥说），`Win + H` 本身是单击切换（按住驱动会让 Windows 反复开始与结束听写）。讯飞语音输入法、搜狗输入法和豆包输入法同样不再提供（前三者按用户要求移除，搜狗在真机上无法正常使用）。配置中保存的这些值都会在加载时迁移为微信输入法，并显示一次迁移提示。

## Smart Focus

- Smart Focus 只接受可验证的编辑控件。应用升级、窗口结构变化、跨权限运行或控件变成只读后，可能需要重新学习。
- 目标应用被关闭、进程不匹配或验证超时会安全停止，不会静默点击固定坐标或向未知窗口发送按键。
- 已学习不等于已验证；保存前必须“立即测试”。
- 手动点击的有效输入框优先。录音过程中不会通过 HUD、Deck 或设置刷新抢走输入焦点。

## VB-CABLE 和蓝牙音频

- “驱动已安装”不等于 `CABLE Input` / `CABLE Output` 端点可用；必须在自检中确认端点、静音状态、输入级别和语音工具实际使用的麦克风。
- VB-CABLE 安装需要用户确认和可能的管理员权限。Vibe Flow 不绕过 Windows 安全机制，也不自动删除共享驱动。
- VB-CABLE 重启恢复、端点重新枚举、蓝牙重连、睡眠/唤醒和多蓝牙设备争用仍需目标机器验证。
- 收音电平低于 10% 时应从距离、朝向、电池和端点级别处理；不要修改冻结增益来掩盖声源问题。

## 功能范围

- 录音仍为按住开始、松开结束；没有 MIC_EXTEND、自动续接、点击切换录音或自动 Enter。
- 不自动发送 AI 消息；录音结束后必须由用户目视检查文字，再按确认键发送。
- 不执行任意 Shell / PowerShell / CMD，不自动启动开发服务器、测试、部署或接受 AI 代码修改。
- Notes Deck、便签 AI、Project Spaces、Capture & Ask 和 Browser Remote Lite 不属于当前主导航功能；历史源码和旧文档只用于追溯，不能当作当前候选版功能承诺。
