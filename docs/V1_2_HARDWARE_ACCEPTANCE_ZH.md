# Vibe Flow v1.2.1 真机验收清单

本清单只用于隔离的硬件候选包。验收期间不得覆盖已安装稳定版，不提交版本标签，也不发布 GitHub 正式安装器。

## 固定参数

| 项目 | 固定值 |
| --- | --- |
| 增益 | `1.0` |
| 音频处理 | `speech` |
| 尾音排空 | `180 ms` |
| 播放端 | `CABLE Input` |
| 工具读取端 | `CABLE Output` |
| 微信快捷键 | `Ctrl + Win` |
| 微信触发方式 | `toggle` |
| 启动等待 | `80 ms` |
| 录音模式 | `hold` |
| 录音内核 | `v1.0.3` |

任何一项变化都必须停止验收并说明原因，不能边测边调参数。

## 1. 环境隔离

- [ ] 候选包版本为 `1.2.1.0`。
- [ ] 候选目录不在已安装 V1.0 目录内。
- [ ] 只运行一套 `VibeFlow`、捕获组件和按键桥接。
- [ ] 用户原配置和已安装程序未被修改。

## 2. 录音状态机

### 100 次实体按下/松开

- [ ] 连续完成 100 次实体按下/松开。
- [ ] 每次 DOWN 只创建一个待启动会话。
- [ ] 按住重复事件没有再次启动。
- [ ] 每次 UP 只结束一次。
- [ ] 没有需要再次点击才能停止。
- [ ] 无双麦克风或第二个语音面板。
- [ ] 每次只播放一次结束提示音。

### 时间边界

- [ ] 10 秒后松开，立即结束。
- [ ] 30 秒后松开，立即结束。
- [ ] 持续到约 60 秒，RC003 边界触发后正常结束。
- [ ] 约 60 秒结束后可重新按住开始下一段。
- [ ] 不自动续接，不创建新工具会话。

### 启动竞态

- [ ] 快速按下再松开，不会在松开后延迟打开工具。
- [ ] 一次实体按下只出现一个 `REMOTE STREAM START`，对应结束只出现一个 `REMOTE STREAM STOP`。
- [ ] 日志包含 `recording_kernel=v1.0.3`，且不包含 `LONG DICTATION` 或 `MIC_EXTEND`。
- [ ] 没有新的实体按下时，不会自行创建下一代录音会话。

## 3. 输入目标

- [ ] 聚焦输入框后录音，文字直接进入原输入框。
- [ ] 仅把鼠标停在输入框上不算聚焦；开始前必须看到插入光标。
- [ ] 转译全程由语音工具直接写入，不进入言灵剪贴板回填。
- [ ] 转译后不自动发送；确认键发送。
- [ ] ChatGPT、Codex 和浏览器文本框各测试一次。

## 4. 按键

| 按键 | 预期 | 结果 |
| --- | --- | --- |
| 录音 | 按住收音、松开结束 | [ ] |
| 功能键短按 | 复制 | [ ] |
| 功能键长按 | 粘贴 | [ ] |
| 上 / 下 / 左 / 右 | 默认标准方向 | [ ] |
| 中间确认键 | Enter | [ ] |
| Home | 显示桌面 | [ ] |
| TV | 打开持久任务视图 | [ ] |

- [ ] TV 打开后页面保持显示，不只闪一下。
- [ ] 上下左右移动任务选择。
- [ ] 确认键进入所选程序。
- [ ] 再按 TV 关闭。
- [ ] 任务视图关闭后，方向键恢复用户配置。
- [ ] 开机、返回和独立音量键在 UI 与生成配置中均不映射。

## 5. 四方向配置

- [ ] 四个方向在页面中按十字方向盘排列。
- [ ] 实体按键实时高亮。
- [ ] 每个方向可选择一个动作并立即测试。
- [ ] 禁用和恢复原方向有效。
- [ ] 重启应用后配置保留。
- [ ] 蓝牙断开重连后配置保留。
- [ ] 升级测试后配置保留。

## 6. 音频和语音工具

- [ ] `CABLE Input` 与 `CABLE Output` 都存在。
- [ ] 微信输入法按稳定档案直接转译。
- [ ] 至少另选 Typeless、豆包或 Windows 语音输入中的一个完成测试。
- [ ] 没有真实音频时首页不显示假波形。
- [ ] 普通日志不包含音频或转译文字。

## 7. 恢复

- [ ] RC003 断开再连接后自动恢复。
- [ ] 遥控器休眠再唤醒后恢复。
- [ ] Windows 睡眠/唤醒后恢复。
- [ ] 锁屏/解锁后恢复。
- [ ] 蓝牙晚于应用启动时可等待并连接。
- [ ] 后台自启动不弹主窗口。

## 8. UI 和自检

- [ ] 新配置默认白天模式。
- [ ] 夜间模式低饱和、文字清晰、无控件重叠。
- [ ] 五个页面均能打开和切换。
- [ ] 11 步教程进度可保存。
- [ ] 10 项自检逐项显示状态、原因和下一步。
- [ ] 修复 Windows 设置后返回应用会自动复检。

## 发布结论

仅当以上项目全部通过，才能把候选版提升为正式版。任一 P0 项失败时，保留日志和候选包，不覆盖旧版，不提交版本标签。
