## 候选版 3（`v2.0.0-candidate.3`，2026-09-13）：相对候选版 2 的变化

> 本节只写**本次候选版**对用户可见的变化；下方「一、相对 V1.5 的重要更新」及之后各节保持原样，仍是 V2.0 相对 V1.5 的完整梳理。

| # | 变化 | 用户会注意到什么 |
|---|---|---|
| 1 | **语音工具收敛为三个** ✔ | 「语音」页和首次设置里只剩 **微信输入法**（默认，`Ctrl + Win` 单击切换）/ **网易八哥说**（右 Alt 单击切换）/ **其他语音工具**（默认右 Shift 单击切换）。Typeless、Windows 语音输入、讯飞输入法、搜狗输入法和豆包输入法已下线；旧配置里保存的这些值会在加载时迁移为微信输入法的稳定参数，并显示一次迁移提示 |
| 2 | **开机自启修复** ✔ | 候选版 2 里「开机自启」关不掉：注册表写入读删除用了不同的值名，关掉后重启又会被注册，日志每次启动都记一次修复。现在写入、回读、删除与安装器共用同一个值名（`Vibe Flow`），关闭后保持关闭 |
| 3 | **发布面修正（未签名说明 + 哈希改指清单）** ✔ | 安装包**未签名**，Windows 会显示「未知发布者」/ SmartScreen；本候选版写出了「更多信息 → 仍要运行」的处理步骤。用户指南不再抄写会随构建过期的资产哈希，改为以随包的 `SHA256SUMS.txt` 为准 |
| 4 | **兼容性与一致性修正** ✔ | 六个页面固定为 首页 · 语音 · 快捷键 · 工作流 · 自检 · 设置；含中文的脚本与 C# 源码补上 UTF-8 BOM（冻结的 Capture 源码有意保持逐字节不变），在英文 Windows 上也能构建和运行；发布构建不再要求仓库里存在未跟踪的 VB-CABLE 驱动包，缺失时由安装器在线下载并校验 |
| 5 | **更新器自测覆盖** ✔ | 更新器的 GitHub-only HTTPS 白名单、版本解析、`SHA256SUMS.txt` 读取和资产查找进入主机自测（含恶意主机与畸形清单负例）；真正联网的下载校验仍需已发布版本才能端到端验证 |
| 6 | **生命周期验收结果** ✔ | 用最终发布产物在本机跑通三条生命周期：干净安装 → 组件校验 → 卸载；未配置干净安装 → 卸载；V1.5 → 候选版升级 → 二次升级 → 卸载。一次性干净账户与跨机器覆盖仍未验证 |

## 一句话

V1.5 是"遥控器能当语音键 + 可自定义按键"；V2.0 把它做成**一台可管理、可自证、可回退的桌面工具**：
六个页面各司其职，文字**固定送进你指定的应用**（工作流），按键从"一个动作"扩展到**短按 / 长按 / 双击**，
并且每个结论都要求**真实证据**（自检给影响、原因码和修复入口，而不是一句"失败"）。

## 一、相对 V1.5 的**重要**更新（按影响排序）

| # | 更新 | 对用户意味着什么 |
|---|---|---|
| 1 | **信息架构从"一页配置"变成六页分工**：首页 / 语音 / 快捷键 / 工作流 / 自检 / 设置 | 想知道状态看首页、想改文字去向看工作流、想改按键看快捷键、出问题看自检 —— 不用在长页面里找 |
| 2 | **工作流：文字固定送进指定应用** | 添加应用 → 学习它的输入框 → 保存 → 学习成功后文字就不再"跟着焦点乱跑"，每行还写明自身状态（还没学习 / 已学习未验证 / 已验证 / 目标已失效） |
| 3 | **三层手势：短按 / 长按 / 双击** | 同一个键最多可挂三种动作；没有单独配置的那层会写清**跟随哪一层** |
| 4 | **双击窗口跟随 Windows 双击速度** | 以前写死 320ms，真机上自然的双击（实测 378ms）会被判成两次短按；现在跟随系统设置（500ms 下限、900ms 上限） |
| 5 | **电源键现在可映射**（本次会话完成） | 电源键（`VK 0xFF` / 扫描码 `E0 5E`）此前被识别却被丢弃；现在可在快捷键页指派短按 / 长按 / 双击 |
| 6 | **Store / UWP 应用可添加、可启动、有图标** | 以前打包应用没有磁盘可执行文件，添加后既不会启动也永远匹配不上 |
| 7 | **首次设置可退出、可续做** | 新增「稍后再说」：关闭向导但保留进度，下次从同一任务继续；向导不再有"走不下去只能关窗口"的死角 |
| 8 | **界面缩放（100% / 110% / 125%）** | 给看不惯小字号、又不方便改 Windows 缩放的用户一个应用内选项（重启生效） |
| 9 | **自检可执行、可解释** | 每项给结论 + 「详情」展开正确状态 / 原因（含 `VF-…` 码）/ 下一步，并提供重新检测与修复入口 |
| 10 | **文案整体简化**（本次会话完成） | 六个页面 + 向导五步逐句过了一遍：去掉重复标签、内部术语和英文状态词，隐私声明保留并改成人话 |

## 二、按功能面的完整清单

### 1. 上手与首次设置
- 五步向导：**确认设备与用法 → 连接并测试遥控器 → 准备本地音频通道 → 选择工具并完成听写 → 开机即用**（与 V1.5 同一套任务）。
- 新增**非破坏性退出**「稍后再说」：保存进度、关闭向导，不把任何任务标成完成。
- 进度可在重启后回到同一任务；步骤完成状态用绿色 ✓ 与「进度已保存」表示，琥珀色只留给"需要你处理"。
- 界面缩放：应用内选择 100% / 110% / 125%，在 Windows 显示缩放之上再放大整个界面。

### 2. 遥控器按键
- 可配置键：**电源（新）/ 上 / 下 / 左 / 右 / 确认 / Home / 功能键 / TV**，每键三层：短按 / 长按 / 双击。
- **录音键（F5）固定**在稳定语音链路上，不可改、不参与分层 —— 这是 V1.5 以来的硬约束，V2.0 未变。
- 快捷键页布局**按实物排**：左列卡片 ∥ 中间遥控器图形与其说明 ∥ 右列卡片；顶格分别是**开机键**与**录音键**。
- 破坏性操作（新建 / 重命名 / 删除 / 导入 / 导出）收进「管理」菜单，不再与常用按钮等权。
- 返回键与独立音量键：**用户态拿不到事件**（无 Raw Input、无翻译键事件、无 `WM_APPCOMMAND`），因此不提供映射，页面文案明说。

### 3. 文字去向（工作流）
- 添加应用：搜索过滤、显示真实图标、**保存即设为当前**（少一步）。
- 只列出**本机实际存在**的应用（过滤文档类条目与外壳程序）。
- 每行给出状态与对应动作：「打开应用并学习」/「选择快捷键 Profile」/「设为当前」等。
- 设置页新增**术语表**，把 `快捷键 Profile`、`Smart Profiles`、`Browser Remote Lite`、`Raw Input`、`Live HUD`、`Context Deck` 各配一句白话。

### 4. 语音链路
- **冻结基线未变**：Capture `1.2.1.0`、录音内核 `v1.0.3`、按住开始 / 松开结束、设备控制的约 60 秒边界、`gain=1.0`、`speech`、`drainMs=180`。
- 录音键隔离：无签名通道时采用**"遥控器在线范围"的钩子隔离**（本次会话把探测周期从 30 秒改为 5 秒，使**每次会话的第一下**也被覆盖）。
- 微信输入法链路：文字由输入法放入剪贴板，Vibe Link 在会话结束后**仅当目标输入框刚验证为可写且持有焦点**时投递一次粘贴；**不读取、不保存、不自动发送**。

### 5. 界面与文案
- 六页标题与导航一一对应；正文最小字号 8pt（不再有 7.x pt）。
- 主题为分段控件（白天 / 夜间 / 跟随 Windows），与"当前选择"的视觉语义一致。
- 自检行默认折叠为一行，点「详情」展开正确状态 / 原因 / 下一步（一屏可见行数明显增加）。
- 单一口径反馈：窗口在前时用窗口内提示卡，窗口不在前台时用 Live HUD，**不再同一句话弹两次**。

### 6. 可靠性与自检
- 用量统计（仅元数据）：会话数、干净完成数、最长间隔；只读时间戳与成功标记，面板自述统计范围。
- 录音键防卡死看门狗：修复"按住不松且无松开边沿"导致语音链路卡住的情形。
- 隔离日志收敛：不再按自动重复频率刷日志（原来约 30 行/秒，2MB 日志约十分钟被冲掉）。
- 自检能报告"录音键从未上报松开"，并给出修复步骤，而不是让遥控器看起来失灵。

### 7. 隐私（V1.5 以来的硬约束，V2.0 全部保留）
- 不读取听写文字、不保存录音、不上传音频、不自动发送；发送始终由你目视确认后手动完成。
- 诊断日志不含录音、转写文字与截图；诊断音频必须每次明确确认。

## 四、仍未验证 / 已知限制（如实列出，不与上面混写）

1. **按设备精确隔离需要签名通道** ✗：代码协议已就绪，缺内核驱动签名与分发。当前是"遥控器在线范围"的替代机制 —— 副作用是**实体键盘的 F5 在遥控器在线时也会被拦截**；非语音键的原生效果仍会透传（设计使然，钩子若吞掉会取消执行动作所需的输入包）。
2. **返回键 / 独立音量键** ✗：不在 Windows 普通输入栈内，用户态拿不到，不提供映射。
3. **安装生命周期** ✔/✗：三条场景已用最终发布产物在本机通过 ✔（干净安装 → 组件校验 → 卸载；未配置干净安装 → 卸载；V1.5 → 候选版升级 → 二次升级 → 卸载）；一次性干净账户与跨机器（Windows 10 / 11）覆盖仍未验证 ✗。
4. **签名与 SmartScreen** ✗：当前安装包未签名。
5. **多 DPI 观感** ✗：自动矩阵覆盖 880×500 / 1280×840 / 1366×768 / 1920×1080 与三种主题；**125% / 150% / 200% 的实际观感**仍需真机确认。
6. **CI** ✗：分支已推送到 `origin/feature/v2-off-key-loop`，但 CI 自 2026-09-03 后仍没有一次真实运行结果。
