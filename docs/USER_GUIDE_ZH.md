# Vibe Link 使用教程

当前公开版本是 **V2.0.0 正式版**；需要回退时使用历史稳定版 **V1.5.0**。安装前请阅读[已知限制](V2_0_KNOWN_LIMITATIONS_ZH.md)。

## 先下载哪个版本

| 版本 | 适合谁 | 下载 |
| --- | --- | --- |
| **V2.0.0 正式版** | 想使用最新 Smart Focus、HUD/Deck、五项首次设置和新版自检 | [安装版 EXE](https://github.com/richlearntodo-debug/vibe-flow/releases/download/v2.0.0/VibeFlow-Setup.exe) · [便携 ZIP](https://github.com/richlearntodo-debug/vibe-flow/releases/download/v2.0.0/Vibe-Flow-Windows-x64.zip) · [SHA256SUMS](https://github.com/richlearntodo-debug/vibe-flow/releases/download/v2.0.0/SHA256SUMS.txt) |
| **V1.5.0** | 需要已经完成稳定验收的旧版工作环境 | [安装版 EXE](https://github.com/richlearntodo-debug/vibe-flow/releases/download/v1.5.0/VibeFlow-Setup.exe) · [便携 ZIP](https://github.com/richlearntodo-debug/vibe-flow/releases/download/v1.5.0/Vibe-Flow-Windows-x64.zip) |

普通用户优先选择 V2.0 的安装版 `VibeFlow-Setup.exe`，下载后用同一 Release 的 `SHA256SUMS.txt` 校验。GitHub 自动生成的源码 ZIP 不是可运行程序。

## [打开 V2.0 正式版图文教程](V2_0_USER_GUIDE_ZH.md)

日常操作：**打开目标对话工具 -> 在“语音”页选择常用应用并测试 -> 点击对话框 -> 按住录音键说话 -> 松开结束 -> 检查文字后手动发送。**

Vibe Flow 负责遥控器、音频通道和快捷键；它不会读取、保存或回填转写文字，也不会把便签、项目编排或自动发送当作录音链路的一部分。工作流未验证时，语音工具可能无法把文字写回当前对话框，请先完成一次 Smart Focus 测试。
