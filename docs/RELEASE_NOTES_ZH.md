# 言灵 · Vibe Flow Remote V1.4 + V1.5 更新说明

**V1.5.0 是本轮正式版；V1.4.0 是不完整预览归档。** 两版属于同一条快捷键与工作流升级，内容在这里合并说明，避免用户来回对照。

## 一句话变化

V1.5 保留已经验证稳定的按住语音链路，把“选动作、找 APP、录快捷键、切工作流、确认是否真的执行”整理成一套完整图形化体验。

## V1.4 完成的基础能力

- 新增可手动切换、新建、重命名、导入和导出的快捷键 Profiles；
- 本机应用选择器同时读取正在运行和已安装应用，并展示名称、来源和图标；
- APP 动作优先聚焦已有窗口，再启动有效 EXE 或 Windows 开始菜单入口；
- Browser AI Profile 使用专用 Browser Back 事件，修复实体左键与 `Alt + Left` 冲突；
- 首页新增真实执行回执，显示实体按键最终解析出的动作、Profile、时间与成功/失败结果；
- Profile 只保存快捷动作，不携带麦克风、VB-CABLE、输入法或增益参数。

V1.4 没有补齐直接快捷键录制和自动 Profile 工作流，因此发布为**不完整预览归档**，不建议普通用户日常使用。

## V1.5 补齐的正式能力

### 直接录制键盘快捷键

用户不再手动输入 `control`、`shift` 等名称。点击“录制键盘快捷键”，在实体键盘按下组合并全部松开即可保存。

- 支持左右 Ctrl、Shift、Alt、Win、F 键、导航键和常见符号键；
- 支持 `Ctrl + Win` 这类只有修饰键的组合；
- 录制期间临时拦截本次按键，避免误触发前台应用；
- 拒绝未知键、半截组合、多个主键和 `Ctrl + Alt + Delete`；
- Host 与 Bridge 使用同一套规范化规则，避免界面显示 A、运行时执行 B。

### Smart Profiles

Smart Profiles 默认关闭，手动 Profile 继续作为稳定默认模式。用户主动开启后，可以把 Cursor、VS Code、浏览器或终端绑定到不同 Profile。

- 前台应用稳定后自动切换动作表；
- 未匹配应用使用明确的回退 Profile；
- 支持“锁定当前”，防止临时切换；
- 同一进程只属于一个 Profile，重复绑定会确定性迁移；
- 不读取窗口标题或用户文字；
- 切换只替换非语音动作，不重启 Host、Bridge 或 Capture。

### 用户体验与文档

- README 最上方提供 V1.5 固定 EXE、ZIP 和 SHA-256 下载；
- 社群二维码提前到下载区之后、教程之前；

## 冻结不变的语音基线

| 项目 | 固定值 |
| --- | --- |
| Capture 文件版本 | `1.2.1.0` |
| 录音内核 | `v1.0.3` |
| 稳定语音档案 | `v11` |
| 交互 | 按住说话，松开结束 |
| RC003 单段边界 | 约 `60 秒` |
| 增益 / 处理 / 排空 | `1.0` / `speech` / `180 ms` |
| 音频端点 | `CABLE Input -> CABLE Output` |
| 微信输入法 | `Ctrl + Win` / toggle / `80 ms` |
| 文本交付 | 语音工具直接写入聚焦输入框，无剪贴板兜底 |

V1.5 没有加入长录音续接、双击手势、宏、多步骤自动化、云端转写或新的录音状态机。

## 硬件边界

当前 RC003 / Windows 蓝牙组合没有稳定上报开机、返回和独立音量键，因此这些按键不提供配置入口。无 Microsoft 签名专属过滤器时，快捷动作使用能识别设备的 Raw Input 安全直通；普通键盘不会触发 RC003 动作，但遥控器原始按键效果可能同时出现。

## 升级建议

1. 从系统托盘退出旧版本；
2. 下载并运行 V1.5 `VibeFlow-Setup.exe`；
3. 启动后确认原有语音工具和快捷键配置仍在；
4. 先保持 Smart Profiles 关闭，完成一次语音和实体按键测试；
5. 确实需要按应用自动切换时再开启 Smart Profiles；
6. 遇到异常运行 10 项自检并导出诊断包。
