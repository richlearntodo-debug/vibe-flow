# 录音模式：稳定边界与硬件限制

适用于言灵 Vibe Flow Remote `v1.1.0` 当前构建。

## 推荐：按住说话

1. 聚焦要输入文字的文本框。
2. 按住 RC003 录音键开始。
3. 保持按住并自然说话。
4. 讲完后松开录音键。
5. 等待结束提示音、文字整理和原输入框回填。

新安装和 schema 18 升级默认使用该模式。按下与松开由两个独立事件处理；松开后不会启动续段或再次打开转写工具。

## 松开如何结束

言灵收到 RELEASE 后按以下顺序收尾：

```text
实体键松开
  -> 等待 RC003 自然 stream_stop（260 ms）
  -> 若停止控制包丢失，精确关闭当前会话
  -> 最多再等待 700 ms
  -> 仍未结束才执行一次本地收尾
  -> 排空 VB-CABLE
  -> 结束一次转写工具会话
```

所有步骤都绑定当前音频 generation。迟到的旧会话事件不能关闭新会话，RELEASE 也不会走连续模式的自动重开路径。

## RC003 的 60 秒硬件边界

真机日志确认，RC003 在一次物理长按约 60 秒时会主动发送：

- Windows 键盘 `F5 UP`。
- ATVV `stream_stop`。
- 当前物理音频流停止。

即使实体键仍被用户按住，Windows 此后看到的也是“已经松开”。`MIC_EXTEND`、精确 `MIC_CLOSE` 后重开和通配重开均无法稳定恢复真实音频，只会出现控制会话或第二个转写麦克风。

因此：

- 稳定按住模式单次以约 60 秒为硬件上限。
- 这不是微信输入法、Typeless 或 VB-CABLE 的限制。
- 软件不会宣传“一次持续长按可无限录音”。
- 长内容应按自然段分次输入。

## 实验：短按连续听写

“连续听写”选项仍保留用于技术验证，但不是默认模式。使用时必须：

1. 短按录音键并立即松开，让原始物理会话在固件到期前自然结束。
2. 说话期间不要持续按住录音键。
3. 完成后再次短按一次结束。

历史真机记录曾在这种前提下完成多分段会话；持续按住到 60 秒的场景已确认无法可靠续接。该模式在完成新的完整硬件回归前不得描述为稳定能力，也不要描述为“绝对无时长限制”。它仍保留 10 分钟安全保护。

## 推荐验收

先验证稳定模式：

1. 确认“录音方式”为“按住说话（推荐）”。
2. 按住 8 到 10 秒并持续说话。
3. 松开后确认只出现一次转写麦克风。
4. 确认只播放一次结束音，文字直接进入原输入框。
5. 空闲 10 秒，确认麦克风不会再次出现。

再做边界验证：

1. 按住并持续说话约 55 秒后松开。
2. 确认音频接近 55 秒、零队列丢包并正常提交。
3. 不把超过 60 秒的持续长按作为通过条件。

## 发布稳定性约束

没有新的 RC003 真机回归前，不应修改：

- 默认录音方式 `hold`。
- 增益 `1.0`。
- 处理模式 `speech`。
- 排空 `180 ms`。
- 微信输入法启动等待 `180 ms`。
- 微信输入法 `Ctrl + Win + Shift` + “AI 整理”单击切换。
- 自动 `CABLE Output` 路由。
- RELEASE 自然停止窗口 `260 ms` 和兜底等待 `700 ms`。

这些参数与按键边界共同构成当前稳定语音路径。
