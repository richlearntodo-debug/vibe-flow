### 正文

**Vibe Link V2.0 正式版发布**（原名「言灵 Vibe Flow Remote」，现已正式更名为 **Vibe Link**）。

**① 这次重点更新了什么**

- **电源键终于能用了。** 以前遥控器电源键能被识别却不生效，现在可以在「快捷键」页给它指派动作；不指派时按键交还 Windows，轻触不会有系统动作。
- **三级快捷键自定义。** 同一个键可以分别设置**短按 / 长按（约 0.6 秒）/ 双击（跟随 Windows 双击速度）**；某一层没单独设置时按上一层执行，卡片上会写明按的是哪一层。录音键例外——它固定在稳定语音链路上，不参与分层。
- **语音工具收敛为三个，设置页更干净。** 微信输入法（默认，`Ctrl + Win`）· **本次新增网易八哥说**（`Right Alt`）· 其他语音工具（`Right Shift`）。同时下线了 Typeless、Windows 语音输入、讯飞、搜狗、豆包——旧配置里存过这些值的，首次加载会自动迁移到微信输入法基线并提示一次，不用手动重设。
- **首次设置和日常使用都更省事。** 向导缩成 5 项任务，中途可以点「稍后再说」：**关掉也保留进度**，下次从同一任务继续；硬件还没就绪也不至于卡住。
- **新增 Live HUD 和 Context Deck。** Live HUD 是不抢焦点的悬浮状态窗，主窗口不在前台也能看到录音状态；Context Deck 是从托盘打开的只读详情面板，一眼看到设备、语音工具、文字目标、Profile 和最近一次按键动作。

**② 你可以用它做什么**

1. 打开目标应用（ChatGPT、Cursor、记事本……都行），在「工作流」里把它加进来并**学习它的输入框**——此后文字固定送进它，不再跟着焦点乱跑；
2. **按住遥控器录音键说话，松开结束**；
3. 看一眼文字有没有进输入框、内容对不对；
4. 没问题再发送——把遥控器确认键指派成回车/确认，还能少碰键盘。

想更快一步：短按 / 长按 / 双击可以各挂一个动作，复制、粘贴、切窗口、打开网页、启动指定客户端都能挂上去。

**③ V2.0 带来的变化**

从「遥控器能录音、能控制按键」，升级为**录音、输入、快捷键和状态反馈一体化**的 Vibe Link。
少找窗口、少点设置、少猜状态——日常使用更直接。

**④ 使用前请先知道（三条，别跳过）**

- **准备**：Windows 10 / 11 x64、**RC003 / MI RC 蓝牙遥控器**、一个语音工具、**VB-CABLE 虚拟音频线**（安装器内置官方驱动包，可选装）。
- **安装包未配置商业签名**：首次运行可能出现"未知发布者"。请先用随包 `SHA256SUMS.txt` 核对文件，再点「更多信息 → 仍要运行」；不要从非项目渠道获取安装包。
- **录音键隔离现状**：在没有签名设备级过滤器之前，录音键使用"遥控器在线范围内"的隔离——**遥控器不在线时，普通键盘的 F5 会原样直通**，这不是签名过滤器的等价替代。
- **隐私**：不读取、不保存、不上传你的转写文字，也不读取网页正文；唯一的外呼是检查 GitHub 更新，可在设置里关闭。

**推荐安装**：`VibeFlow-Setup.exe`（8.29 MB）。**从 V1.5 可直接覆盖升级，已有配置会自动保留**（升级路径已在 CI 上通过验收）。
