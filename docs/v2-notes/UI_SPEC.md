# V2.0 Notes Deck UI 规范

## 信息架构

主导航只保留：首页、便签、快捷入口、自检、设置。录音和快捷键稳定设置不消失：它们在首页状态卡、设置和相关入口中可达，但不再用“项目/Workspace”作为产品核心概念。

## 首页

首页回答四个问题：现在能不能用、便签在哪里、当前快捷入口是什么、下一步该做什么。首屏主 CTA 只能有一个：未配置时是“新建第一条便签”，已有便签时是“继续最近便签”。状态必须用图标、文字和颜色同时表达，不能将“已启动应用”写成“输入框已就绪”。

## 便签页与 Deck

便签页采用宽窗左列表右正文、窄窗列表/详情切换。Deck 是同一数据服务的轻量独立窗，不是第二个笔记库；固定、置顶、关闭是三个独立状态。Deck 失焦不自动关闭，也不为了刷新、保存或 AI 返回抢回外部应用焦点。录音期间不打开新编辑框、不执行聚焦、不排队动作。

## 快捷入口

页面文案使用“APP 快捷入口”，不使用“项目现场”“Workspace”“webflow”。每个入口显示：名称、APP、能力等级（输入框已就绪/已打开待确认/仅启动切换/未验证）、快捷键、最近结果。ChatGPT 当前只能按实际证据显示“已打开，输入框待确认”。

## 状态和错误

统一状态：idle、checking、running、success、warning、error、canceled。失败必须包含发生了什么、本次没有执行什么、可能原因、一个修复动作、重新检测和错误码。保存成功与 Bridge ACK、APP 激活与输入框验证、录音结束与文字到达都必须分开表达。

## 视觉与可访问性

- 保持 WinForms、DPI 自动缩放和键盘导航。
- 画布使用浅色 `#F7F8FA` / 内容面 `#FFFFFF`，深色使用 `#11161D` / `#1A222C`；强调色克制使用青蓝 `#0C7F8E`。
- 8 DIP 网格，常用按钮 36–40 DIP，中文正文 14–16 DIP；避免在小窗中强行两栏。
- 不使用大面积霓虹、装饰性渐变、营销 Banner 或无意义图案。
- 100%/125%/150%/200% DPI、1366x768 和 1920x1080 必须检查长中文、按钮和首屏主操作。
