# 言灵 · Vibe Flow Remote 功能看板

V2.0 候选版在 V1.5 稳定录音和按键基础上，主线是“锁定目标、按住说话、检查文字、手动确认”：稳定语音输入、快捷键 Profiles、工作流验证和自检。

旧 Project Spaces、Capture & Ask 和 Browser Remote Lite 仅作为历史配置/文档索引保留，不是当前首页、首次设置或主导航功能。

[V2.0 候选版教程](V2_0_USER_GUIDE_ZH.md) · [V1.5 稳定版下载](https://github.com/richlearntodo-debug/vibe-flow/releases/tag/v1.5.0) · [全部版本下载](VERSION_ARCHIVE_ZH.md)

## 核心能力

| 模块 | 重点功能 | 典型用途 |
| --- | --- | --- |
| **语音输入** | RC003 麦克风、按住说话、松开结束、真实收音状态 | 在 ChatGPT、Codex、Cursor、VS Code、浏览器和其他文本框中输入语音 |
| **Smart Focus** | 学习可编辑控件、测试、验证、激活和安全回退 | 只向正确的工作流输入框聚焦，失败时不发送按键或图片 |
| **Live HUD / Context Deck** | 非激活浮层、只读按键图和统一真实回执 | 看清设备、语音、目标和最近动作，不抢录音焦点 |
| **语音工具适配** | 微信输入法、Typeless、Windows 语音输入及自定义全局快捷键工具（豆包输入法自 V2.0 起不再提供） | 保留用户熟悉的转译和标点能力，结果由用户检查 |
| **快捷键录制** | 直接按下实体键盘组合完成映射；自动拦截录制过程 | 配置命令面板、搜索、撤销、运行、终端等个人快捷键 |
| **应用控制** | 发现正在运行与已安装 APP，显示名称和图标，优先切换已有窗口 | 快速进入常用 AI 客户端、编辑器、终端或浏览器 |
| **网页动作** | 打开用户配置的 HTTPS 地址 | 一键进入 ChatGPT、Claude、DeepSeek、GitHub 或项目页面 |
| **快捷动作** | 截图、复制、粘贴、撤销、重做、系统、媒体和自定义组合键 | 减少反复回到键盘操作的次数 |
| **Profiles** | 内置四套 Profile，新建、重命名、复制、导入和导出 | 为 Coding、浏览器和终端保存不同按键布局 |
| **手势分层** | 每个可配置实体键可分别绑定短按、长按和双击三层动作，每层一个动作；未单独配置的层回退并在卡片上写明回退目标 | 一个实体键承载三种快捷动作，减少来回切换配置的次数 |
| **使用统计（仅元数据）** | 设置页显示会话次数、成功率与最长间隔，全部由本地回执日志聚合；不读文字、不新增落盘、不上传 | 了解自己用得怎么样，同时不产生任何新的个人数据 |
| **用语片段（用户自备文本）** | 自己填写常用短语，绑到按键或手势层；按下时按字符直接写入当前输入框，不经过剪贴板 | 一键输入邮箱、地址、常说的开场白，不用反复手打 |
| **Smart Profiles** | 可选根据当前前台 APP 自动切换，支持锁定与回退 Profile | 在编辑器、浏览器和终端之间切换时自动使用对应配置 |
| **自检中心** | 检查组件、蓝牙、按键、真实音频、VB-CABLE、语音工具、自启动和完整会话 | 快速定位“连接了但不能说”“有音频但不转译”等问题 |
| **体验与隐私** | 白天、夜间、跟随 Windows；执行回执；日志限长 | 清楚看到当前状态，同时不保存普通录音和转译文字 |

## 一句话工作流

```text
单击目标输入框 -> 按住遥控器录音键说话 -> 松开等待转译 -> 检查文字 -> 确认键发送
```

## 可配置按键

| 实体按键 | 默认动作 | 配置能力 |
| --- | --- | --- |
| 录音键 | 按住收音，松开结束 | 固定稳定链路，不参与自定义，也不参与手势分层 |
| 上 / 下 / 左 / 右 | 标准方向 | 可配置单击动作 |
| 中间确认键 | `Enter` | 可配置单击动作 |
| Home | 显示桌面 | 可分别配置短按与长按 |
| TV | 持久任务视图 | 可配置单击动作 |
| 功能键 | 短按复制、长按粘贴 | 可分别配置短按与长按 |

### 手势分层（V2.0）

每个可配置实体键在快捷键页都有三行独立动作：**短按 / 长按 / 双击**。

- 某一层没有单独配置时会回退到上一层（双击 → 长按 → 短按），卡片上会写明回退目标，不会谎称这一层有自己的动作；
- 双击判定窗口为 0.32 秒，长按阈值约为 0.65 秒；
- 每一层右边的「▶」可单独测试，不必真按遥控器；
- 绑了双击的按键，短按会改为**松手时触发**（双击必须观察松手才能判定）；清空该键双击即可恢复按下即触发；
- 还没有配置额外层的按键保持 V1.5 行为：按下即执行，不引入松手延迟；
- 录音键固定在稳定语音链路，**不参与手势分层**。

## Profiles 与自动切换

V1.5 内置通用导航、Vibe Coding、浏览器 AI 和 Terminal Agent。Smart Profiles 默认关闭，普通用户可以继续使用最简单的手动模式；需要自动化时，再把指定应用绑定到对应 Profile。

## 稳定性边界

- RC003 当前稳定单段录音约 60 秒；V1.5 不包含长录音续接；
- 开机、返回和独立音量键没有稳定 Windows 事件，因此不提供配置入口；
- 不提供任意命令执行、脚本或后台读取输入内容；每个按键层只能绑定一个已有动作，不提供多步骤序列；
- 语音文字由用户选择的语音工具生成，言灵不读取、不保存，也不通过剪贴板回填；
- 使用统计只读本地回执日志里的时间戳与成功/失败标记，不读窗口标题、目标名、设备地址或任何文字；统计范围限于当前日志窗口，日志限长后旧记录会随滚动丢弃；
- 用语片段只保存**你自己填写**的文本（本机 `UserData\snippets.json`，原子写 + `.bak`），不接收也不读取第三方转写文字；输入用逐字符 Unicode 键盘事件直接写入，不经过剪贴板，日志只记长度不记内容；
- Smart Profiles 是可选功能，不会修改麦克风、VB-CABLE 或语音参数。

## 发生问题时

先打开“自检”，按页面提示修复蓝牙、音频或语音工具配置。仍无法解决时，导出诊断包并扫码加入用户社区。
