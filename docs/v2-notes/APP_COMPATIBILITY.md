# APP 快捷入口兼容性矩阵

| APP | 当前证据 | 首版状态 | 说明 |
| --- | --- | --- | --- |
| ChatGPT 桌面端 | 可启动/激活；当前 UIA 没有 `ControlType.Edit` | 已打开，输入框待用户确认 | 不发送文本，不伪称 Smart Focus 已就绪 |
| Cursor | 旧 FocusTarget 适配器存在，但本轮尚未重新完成真实 UI 验证 | 未验证 | 只有真实学习/测试通过后才升为输入框已就绪 |
| VS Code | 可作为用户选择的本地 APP，但没有本轮真实目标证据 | 仅启动/切换 | 不保存窗口标题正文或坐标 |
| 自定义 APP | 用户明确选择的可执行文件 | 仅启动/切换 | 不附加任意命令参数，不读取窗口文本 |

## 状态定义

- 输入框已就绪：有同一 APP 进程和可编辑焦点的可验证证据。
- 已打开，输入框待确认：启动/激活成功，但没有足够的 UIA 编辑控件证据。
- 仅启动/切换：只能确认进程启动或前台激活。
- 未完成：目标不存在、冲突、取消或验证失败；不分发按键或粘贴。

真实设备、ChatGPT/Cursor/VS Code 多窗口、DPI 和用户快捷键冲突仍需手工验证。
