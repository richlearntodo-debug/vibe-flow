# 言灵 · Vibe Flow Remote 1.0.3

这是 `1.0.3` 正式版，集中完成了最近两轮的稳定性、首次使用流程和界面升级。它解决 Windows 登录后按键桥接、RC003 蓝牙语音服务和本地转写工具启动顺序不一致时，第一次录音无法唤起转写的问题；同时加入完整自检与恢复日志，并重新设计首页遥控器和快捷方式配置页。已经通过 RC003 真机验证的语音传输参数和按键行为保持不变。

## 当前支持

- **转写工具**：微信输入法、Typeless、Windows 语音输入、Voquill，以及可配置快捷键的其他语音工具。
- **遥控器操作**：录音键按住听写、确认键发送、Home 显示桌面、TV 任务切换、功能键打开或切回所选客户端、方向键导航和长按上 / 下调节系统音量。
- **客户端快捷启动**：ChatGPT、DeepSeek、Claude、Cursor、VS Code、Windsurf，以及用户自定义快捷操作。
- **隐私模式**：音频默认仅在本机转发，不读取转写文字，不保存普通听写录音；一次性诊断音频必须由用户明确确认。

## 详细更新

- 修复开机后 RC003 ATVV 服务尚未就绪时，第一次录音键请求丢失的问题。
- 增加录音键按住状态的跨进程交接：服务就绪时仅恢复仍在按住的请求，松开后绝不会延迟启动录音。
- 增加后台主程序自恢复：采集进程缺失或卡在连接阶段时，录音键会触发自动拉起或受控重连。
- 修复应用语音设置后，旧采集进程的延迟退出回调误伤新链路状态的问题，确保重连计时与就绪状态属于当前进程。
- 三个可执行组件统一写入 `1.0.3` 文件版本，便于识别覆盖升级不完整或组件混用问题。
- 开机后台预热用户选择的微信输入法、Typeless 或 Voquill；避免快捷键已经发出，但本地转写客户端尚未运行。
- RC003 已配对时优先复用 Windows GATT 缓存，缓存无效时自动回退实时发现，缩短开机后的蓝牙语音就绪时间。
- 新增 `vibe-flow-host.log`，记录主程序启动、转写工具就绪、录音唤醒和自动恢复决策，方便排查重启后的问题。
- 首页改为“管理语音桥接”，避免把暂停操作放在最主要入口；系统托盘会根据当前状态明确显示“启动”或“暂停”。
- 已验证音频档案默认锁定，只有确认进入高级调整后才能修改，并可随时一键恢复。
- 首次向导改为中文步骤反馈，开机启动默认不勾选，连接成功后按钮会及时更新；完整教程新增五步对应截图。
- 按参考遥控器重新建立细长银色机身、方向环、圆形按键、纵向音量摇杆、NFC 标记和底部留白，缩小图标与笔画；参考照片本身不包含在软件中。
- 快捷方式页改为清晰的左右双栏：左侧配置，右侧实体遥控器实时定位；悬停或选择按键时会同步高亮对应位置。
- 优化首页信息层级、听写步骤、核心按键速查、录音波纹、五个侧栏图标、精确版本号和“检查更新”入口。
- 保持稳定档案 v11、`1.0x`、清晰增强、180 ms 排空、自动麦克风路由和已验证按键映射不变。

## 升级说明

安装版可以直接运行新安装包覆盖升级。免安装版请解压到新目录后运行 `VibeFlow.exe`。程序会保留已有的转写工具、快捷键、开机启动、声音反馈和语音参数配置。

升级后在“偏好设置”确认版本为 `1.0.3`，再到“连接与自检”运行一次检查。若诊断里的程序路径仍指向旧目录，请从系统托盘退出旧实例，再从开始菜单打开新版本。

## 语音链路保持不变

本次没有修改稳定档案 v11：`1.0x` 灵敏度、清晰增强、180 ms 排空、`CABLE Input` 播放端、自动默认麦克风路由、音频排空后恢复原麦克风。正常听写不保存录音，不读取转写文字，也不自行上传音频。

## 已知边界

- 仅支持 Windows 10/11 x64 和已验证的 RC003 / MI RC 遥控器，不提供 Android APK。
- VB-CABLE 是唯一必须额外安装的本地驱动，因第三方许可不包含在发布包中。
- 独立返回键和音量 +/- 键没有上报稳定 Windows 事件；系统音量使用长按方向上 / 下。
- Voquill 和其他第三方工具需要根据已安装版本核对全局快捷键；其账号、网络、识别和隐私策略由对应工具负责。
- 安装包尚未进行商业代码签名，请只从本仓库 Releases 下载并核对 SHA-256。

完整安装、配置、验收、问题排查和卸载步骤见 [中文使用教程](USER_GUIDE_ZH.md)。
